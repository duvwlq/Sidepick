# data/ - 사이드픽 데이터셋

부업 실패 사례 데이터셋입니다. 현재는 **자체 픽플리 설문 100건**이 메인 데이터이며,
초기 네이버 지식iN 기반 49건 크롤링 데이터는 `archive/` 아래 참고용으로 유지합니다.

## 파일 목록

| 파일 | 설명 | 행 수 |
|---|---|---|
| `failure_cases_100.csv` | 픽플리 설문 100건 원본 정제본 | 100 |
| `failure_cases_100_tagged.csv` | 메인 데이터셋, LLM 자동 태깅 결과 포함 | 100 |
| `matching_table.json` | 카테고리 x 어려움 7 x 7 = 49개 성공 가이드 매칭 | 49 |
| `archive/` | 49건 크롤링 데이터와 레거시 산출물 보관 | - |

## 데이터 출처

- 자체 설문조사 (픽플리, n=100, 2026.04)
  - 부업 실패 경험자 대상 자기보고 설문
  - 응답자가 직접 작성한 회고와 정량 데이터 포함
  - 투자금, 수익, 기간, 시간, 실패 원인, 어려움, 자유서술 수집
- 개인정보 비식별화 처리 후 분석에 활용
- AI 분석 시 원문을 그대로 노출하지 않고 요약 및 재구성 후 활용
