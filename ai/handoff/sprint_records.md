# 🛡️ Git Flow / 팀워크 증빙

## 브랜치 전략
- `main`: 보호 브랜치, PR base
- `feature/ai`: AI 자산 전용 (오혜림)
- `feature/backend`: BE 모노레포 (정근원)
- `Sidepick-merge-branch`: 현재 FE 표준 (BE 담당자가 통합)
- `feature/ai-007-experience-detail`: PR #5 (closed, BE 표준 정합성 위해)

## 커밋 규칙
- Conventional Commits 한국어 본문
- 예: `feat(ai):` / `feat(fe):` / `fix(ai):` / `chore(ai):` / `docs(handoff):`
- Co-Authored-By 줄 X (사용자 정책)

## PR 기록
- PR #5 (feature/ai-007-experience-detail) — closed (의사결정: Sidepick-merge 통합)
- 그 외 BE/FE PR은 별도 본인 GitHub에서 확인

## 업무 밸런스 (3명 최종)
| 팀원 | 담당 영역 |
|---|---|
| 오혜림 | 팀장 / AI 전체 / PM / FE 일부 |
| 정근원 | BE / 클라우드 / FE |
| 이은성 | PD / PM 일부 |

→ 각자 역할이 명확히 분담되어 있고, 인원 변동에도 균형 유지
