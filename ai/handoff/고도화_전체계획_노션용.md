## 1. 고도화 수행 계획 개요

### 🤖 AI / 콘텐츠
- FAQ 챗봇 (LM 기반) → **부업 상담 에이전트로 격상**
- 실패패턴 그래프 ("나와 같은 실수를 한 사람 X%")
- 실패 시점 분포 시각화
- 업종별 통계 페이지
- 내 분석 결과 히스토리
- 성공사례 추가 (원글 + AI 분석글)

### 🧠 AI 에이전트 (신규)
- **[에이전트 A] 글 작성 보조 에이전트** — 초안 분석 후 부족한 정보를 질문 카드로 수집, 보완된 정보로 더 정밀한 분석 실행
- **[에이전트 B] 리포트 자기검증 루프** — AI가 생성한 리포트를 스스로 평가, 기준 미달 시 재검색·재생성 후 출력
- **[에이전트 C] 부업 상담 에이전트** — 툴(FAISS 검색, 통계 조회, 성공사례 검색)을 스스로 선택해 멀티스텝 실행, 맞춤 리포트 생성
- **[에이전트 D] 프로액티브 알림 에이전트** — 유저 액션 없이 조건 감지(3개월차 진입, 새 성공사례 등록 등) → 자율적으로 알림 발송

### 👤 유저 경험
- 회원가입 시 부업 상태 선택 (경험자/예정자, 버튼으로 전환 가능)
- 회원가입 시 관심 분야 체크 → 메인 홈 개인화 노출
- 북마크/저장
- 공감/반응 버튼 ("나도 이런 실수 했어요")
- 내 글 수정 기능
- 실패사례 → 성공사례 연결 버튼
- SNS 공유 (내 분석 결과 카드)

### 🎨 디자인
- 브랜드 컬러 확정
- 전체 디자인 개편 (현재 모노톤 → 컬러 적용)

### 📋 역할 분배
- **팀장**: PM + AI + FE 일부 (실패→성공 버튼, 브랜드 컬러 FE 적용)
- **PD**: 전체 디자인 + 베타테스트 전담
- **BE**: 클라우드 + BE + FE 대부분

## 2. 성공사례 데이터 수집 계획

| 1주차 | 5/18~5/24 | **[설문 폼 제작]** 성공 경험자 대상 구글폼 제작 (업종, 성공요인, 월수입, 소요기간, 실패와의 차이점) → 배포 | PD |
| 2주차 | 5/25~5/31 | **[크롤링 데이터 정제]** 수집 데이터 클렌징 및 구조화 (업종, 성공요인, 소요기간, 수입규모) | 팀장 |
