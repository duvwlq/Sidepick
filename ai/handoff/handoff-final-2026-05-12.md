## 4. 주요 의사결정 기록

### 시점 매핑 시비 회피
- **결정**: 스프린트 기록 PDF는 두 가지 버전 분리
  - **학원 제출용**: 노션 데일리 기록 그대로 (사실만, 일차 표기 유지 / 주차·구체 날짜 제거)
  - **본인 참고용**: 추정 기반 + 단계 표기로 변경 (어필 포인트 유지)
- **이유**: 추정 시점이 실제와 어긋남 → 강사 질문 시 위험 회피

### 발표 스크립트 구성
- **결정**: 시연 영상 4분 풀 + 멘트 6분 = 총 10분
- **이유**: 사용자가 시연 영상 4분 그대로 사용 결정 (옵션 A)

### 시연 영상 보이스오버
- **결정**: 3인칭 narrator + 박윤지 페르소나 시점
- **이유**: 시연 영상에 화자가 외부 narrator 형태 자연스러움

### PPT 슬라이드 15 변경
- **결정**: "AI 강사님 바이브코딩 우려" + "5단계 시스템 자체 설계" 어필 강화
- **이유**: 슬라이드 12(자체 IP 박스)와 시각적 연결 → 발표 스토리라인 일관성

### Sidepick GitHub 공개 전환

- **체크리스트**: `.env` 미커밋 / API 키 노출 없음 / `ai/handoff/` 비공개 처리 완료

## 5. 발표 어필 핵심 포인트 (정리)

### 1순위 — 자체 IP (가장 강력)
- **AI 강사님 "바이브코딩 우려" 직접 지적** → 자체 IP 강조 피벗
- 5단계 AI 시스템 전체 자체 설계 (도구 선택 + 흐름)
- SBERT + FAISS 매칭 로직 자체 구현
- 49 가이드 매트릭스 직접 작성 (7×7)
- Advice 조합 로직 (BE 내부, 별도 LLM 호출 X)
- Claude API는 5단계 중 1단계 원인 분석만

### 2순위 — 강사님 피드백 100% 반영
- 5명 영역 서면 피드백 (중간점검 발표 후)
- PM 강사님 2회 / 클라우드 강사님 1회 / AI 강사님 1회 / PD 강사님 1:1
- 총 6회 멘토링 + 1회 중간점검 서면 피드백

### 3순위 — 트러블슈팅 / AI 단계 진화
- T5 (학습 한계) → SBERT (매칭) → LLM API (생성·운영 반영)
- 한계 인지 후 적합한 도구 선택 → 5단계 시스템 통합

### 4순위 — 인원 변동에도 운영 시스템 완성
- 6명 → 5명 → 4명 → 3명
- 각자 역할 확장 (오혜림: 팀장+AI+PM+FE / 정근원: BE+클라우드+FE / 이은성: PD+PM)

### 5순위 — 서비스 방향성 피벗
- 사례 공유 메인 → **조회·검색 메인** (탐색 위주 동선)
- 글쓰기 4→3단계 / 자율서술 50→10자
- 베타테스트 + 강사님 피드백 동시 반영
