# 📊 슬라이드 1-1. Background + Research

## 헤더
**"부업 시장은 커지지만, 실패 경험은 비정형 정보로 흩어져 있다"**

## 본문 1 — Background (시장 통계)
- 큰 박스 강조:
  - **부업하는 직장인 40만 명 +**
  - **30대 16.8% 증가**
- 출처 (작은 글자): 자유일보 / 중부일보 / 더 페어 뉴스 / 뉴스1

## 본문 2 — Research (설문 13명, 2026.03.19~22)
가로 막대 그래프 또는 표:
| 부정적 경험 | 비율 |
|---|---|
| 투자 대비 손실 발생 | **33%** |
| 수익 거의 발생하지 않음 | **28%** |
| 기대와 현실의 차이 | 22% |
| 지속하기 어려움 | 11% |

## 본문 3 — 결정적 인사이트 (강조 박스)
- **실패 후 유사 사례 찾는 경험: 10/13명 (77%)**
  - 실패 원인 비교: 50%
  - 비슷한 상황 확인: 40%

## 핵심 인사이트 (하단 강조)
> "사용자들은 실패 경험을 찾지만, 형식이 제각각이라 비교가 어렵다"

## 발표 멘트 (22초)
"부업하는 직장인 40만 명, 30대 16.8% 증가했습니다. 부업 경험자 13명 설문 결과, 투자 손실 33%, 수익 부족 28% 등 부정적 경험이 다수입니다. 특히 77%가 실패 후 유사 사례를 찾아본 경험이 있었고, 이유는 실패 원인 비교와 비슷한 상황 확인입니다. 사용자들은 실패 경험을 찾지만, 형식이 제각각이라 비교가 어려운 상황입니다."

## 디자인

# 📊 슬라이드 1-2. Problem

## 헤더
**"사용자들은 실패 경험을 접하지만, 의사결정에 활용하지 못합니다"**

## 본문 — Problem 정의 (중앙 큰 박스)
> "부업 경험 사례는 다양하게 존재하지만, 구조화되지 않은 정보로 인해 유사 사례를 비교·탐색하고 의사결정에 활용하기 어렵습니다."

## 핵심 원인 3개 박스 (가로 배치)

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│  ❌             │   │  🔍             │   │  💭             │
│  비교 분석의    │   │  유사 사례를    │   │  실패 이후      │
│  어려움         │   │  보고 싶음      │   │  의사결정       │
├─────────────────┤   ├─────────────────┤   ├─────────────────┤
│ 온라인 상 경험  │   │ 나와 유사한     │   │ 다음 행동에     │
│ 형식 제각각     │   │ 사례를 찾아     │   │ 대한 판단       │
│ → 비교/검색/    │   │ 확인하고 싶음   │   │ 기준이 필요     │
│   분석 어려움   │   │                 │   │                 │
└─────────────────┘   └─────────────────┘   └─────────────────┘
```

## 핵심 메시지 (하단 강조)
> **"정보 부족이 아닌 구조 부재의 문제"**

## 발표 멘트 (15초)
"비정형 정보로 흩어진 실패 경험은 비교가 어렵습니다. 사용자는 자신과 유사한 사례를 찾고 싶지만 못 찾고, 결국 실패 이후 의사결정 기준을 형성하지 못합니다. 정보가 부족한 게 아니라 구조가 없는 게 문제입니다."

## 디자인
- Problem 정의 박스: **보조 회색** `#6B7280` 배경
- 원인 3박스: 가로 배치, 각 박스에 아이콘
- 핵심 메시지: **브랜드 파랑** `#2563EB` 강조

```
              [메인]
                 ↓
            [검색/탐색] ← 카테고리/키워드 선택
                 ↓
       ┌─────────────────────┐
       │ [사례 상세 조회] ⭐ │ ← 핵심 가치 지점
       ├─────────────────────┤
       │ • 본문 + 메타 grid  │
       │ • 핵심 이슈 칩      │
       │ • AI 가이드 1·2·3   │
       │ • 유사 사례 3개      │
       └─────────────────────┘
                 ↓
       [내 경험 분석] (선택 진입)
                 ↓
       [분석 결과 확인] → 의사결정
```

```
│           (경험 작성은 선택)            │
└────────────────────────────────────────┘
```
