### 🟢 Tool 호출 방식 — 최종 결정

```
Tool 1: search_cases(query, type="failure" or "success", limit=3)
        → FAISS 통합 인덱스, type 메타데이터로 필터링
        → 성공사례 검색은 type="success"로 통합
Tool 2: query_stats(category, metric)
        → 업종별 통계 / 실패 요인 TOP3

총 2개 Tool
```

**성공사례 데이터 구조 — 실패와 비슷한 스키마로**
- 공통 필드: 원글 / 업종 / 기간 / 투자금 / 키워드 / AI 분석 / 메타 grid
- type별 추가:
  - failure: 실패 패턴, 핵심 이슈 칩
  - success: 성공 요인, 나와의 차이점

### 🟢 토큰 한도 — 하이브리드 라우팅

**[단순 질문]** = Plan B (단순 RAG) 자동 라우팅
- 일일 한도: 무제한 (또는 매우 높게)
- 비용 매우 적음

**[복잡 질문]** = ReAct (멀티스텝)
- 일일 한도: 10,000 토큰
- ReAct 발동 자체를 줄여서 비용 관리

**라우팅 규칙**:
- 질문 길이 < 30자 → 단순 RAG (Plan B)
- 질문에 "비교", "통계", "유사", "성공사례" 키워드 포함 → ReAct
- 그 외 → 단순 RAG

### 🟢 Plan B 트리거 5가지 조건

| # | 조건 | 동작 | 사용자 안내 | 빈도 예상 |
|---|---|---|---|---|
| 1 | max_iterations 초과 (7회) | 마지막 Tool 결과 + 단순 LLM 응답 | ❌ 안내 X | 10~20% |
| 2 | Tool 결과 0건 | 기본 응답 템플릿 | ✅ "비슷한 사례 없음" | 5~10% |
| 3 | LLM 파싱 실패 | 재시도 1회 → 단순 RAG | ❌ 안내 X | 1~3% |
| 4 | 응답 타임아웃 30초 | 즉시 RAG fallback | ✅ "시간이 더 필요" | 3~5% |
| 5 | Tool API 에러 | 재시도 1회 → ReAct 중단 | ❌ 안내 X | 1~3% |

**Plan B 발동 합계 예상**: 20~40% (정상 ReAct = 60~80%)
→ 4주차 50개 시나리오 테스트로 실측 예정

### 🟢 환각 방지 6중 안전장치 ⭐ (Sonnet 단일 보완)

1. **에이전트 B 자기검증 루프** (핵심)
   - 신뢰도 < 0.7 발동 → 재생성 1회 → 결과 캐싱

2. **시스템 프롬프트 환각 방지 룰**
   ```
   - Tool 결과에 명시된 정보만 사용하라
   - 근거 없는 통계나 수치를 만들지 마라
   - 정보가 부족하면 "비슷한 사례를 찾지 못했어요"라고 답하라
   - 모든 답변은 case_id 인용으로 끝나야 한다
   ```

3. **case_id 인용 강제 + 응답 검증 로직**
   - LLM 응답에 case_id 인용 여부 검증
   - 인용 없으면 환각으로 판단 → 재생성 (max 1회)

4. **카테고리 화이트리스트** (3중 방어)
   - 시스템 프롬프트에 명시
   - 응답 파싱 후 enum 검증
   - 검증 실패 시 재생성

5. **DB 캐시 우선** (검증된 답변)
   - 통계 7d / 사례 24h
   - 캐시 hit 시 환각 없음

6. **응답에 신뢰도 표시**
   - "💡 이 답변은 X건의 실제 사례를 기반으로 작성되었습니다"

**환각 합격 기준**: 자기검증 적용 후 < 3%

## 8. 활용 가능한 멘트 (포트폴리오/면접용)

> "LangChain ReAct 기반 부업 상담 에이전트를 자체 구현했고, FAISS 검색 + 통계 조회 Tool 2개를 자율적으로 조합해 멀티스텝 답변을 생성합니다."

> "환각(Hallucination) 위험은 자기검증 루프 + case_id 인용 강제 + 카테고리 화이트리스트 + DB 캐시 등 6중 안전장치로 관리했습니다."

> "비용 관리는 하이브리드 라우팅으로 단순 질문은 RAG, 복잡 질문만 ReAct 발동시켜 사용자당 일일 토큰 한도를 보장했습니다."

### AI 강사님 피드백 반영 어필
> "강사님께서 'max_iterations 3은 너무 빡빡하고 응답 시간 15초는 초과 가능하다'고 지적해주셔서, 7과 30초로 조정하고 스트리밍 응답을 추가했습니다."

> "강사님께서 '단일 모델이 성능은 더 좋지만 환각 위험이 있다'고 알려주셔서, Sonnet 단일 모델을 선택하되 환각 방지 6중 안전장치로 보완하는 구조로 설계했습니다."
