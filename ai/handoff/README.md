## 📌 사용 가이드

### 새 컴퓨터에서 작업 시작 시
1. `git pull origin feature/ai` 로 최신 인수인계 자료 받기
2. `ai/handoff/` 의 가장 최신 `handoff-{날짜}.md` 부터 읽기
3. 그 안의 "현재 상태" 섹션과 "다음 단계" 섹션 확인

### 새 클로드AI 세션 시작 시 (claude.ai 웹 / 다른 머신 등)
이 폴더의 자료를 첨부하거나 내용 복사:
1. **가장 최신 인수인계 문서 1개** (예: `handoff-2026-05-07.md`)
2. **이전 인수인계 문서 (선택)** — 더 깊은 컨텍스트 필요할 때
3. **BE React 가이드** — FE 관련 작업 진행 시

같은 머신의 Claude Code 세션은 메모리 시스템이 자동 로드되니까 굳이 첨부 안 해도 컨텍스트 이어짐. 다른 머신/다른 클로드 인스턴스만 첨부.

### 인수인계 문서 업데이트 규칙
- **파일명 패턴**: `handoff-YYYY-MM-DD.md`
- **작성 시기**: 큰 작업 단위 끝났을 때 (티켓 1~2개 완료, 분기점 회의 후 등)
- **위치**: 항상 `ai/handoff/` 안에
- **commit 메시지**: `docs(handoff): [날짜] [핵심 내용]` 형태
