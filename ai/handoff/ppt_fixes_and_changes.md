## 3. P1 — 순서 조정 권장 2건 (위 순서표 작업 1·2·3 참조)

### 순서 조정 1: 시장 ↔ 문제 정의
**이유**: 발표 흐름이 "시장이 크다 → 그런데 문제 있다 → 누가 겪나(페르소나) → 우리 솔루션"이 자연스러움. 시장 분석이 페르소나 뒤에 오면 임팩트 약화

### 순서 조정 2: 사용 흐름 + 시연 영상 → 핵심 기능 다음으로
**이유**: 서비스 소개 다음에 사용 흐름이 자연스러움. AI 5단계와 디자인+BE 다음에 사용 흐름이 오면 흐름 어색

## 4. 슬라이드 15 변경안 (강사님 피드백 매트릭스) ⭐

### 5가지 수정 체크리스트

```
□ ① CHAPTER 헤더 "02 시장 분석" → "05 프로젝트 회고"
□ ② 슬라이드 제목 변경
□ ③ PD 강사님 우리 대응 셀에 "+ FAQ 게시판" 추가
□ ④ AI 강사님 행 2개 셀 수정 (가장 중요)
□ ⑤ 하단 배너 강화
```

### ② 슬라이드 제목
```
변경 전: "강사님 피드백 — 5개 영역 강사님 피드백, 100% 반영했습니다"
변경 후: "강사님 피드백 — 6회 멘토링 + 중간점검 서면 피드백 100% 운영 반영"
```

### ③ PD 강사님 우리 대응 셀
```
변경 전: 카테고리 구체화(6×5개 서브) / 메타 grid 시각화
변경 후: 카테고리 구체화(6×5개 서브) / 메타 grid 시각화 / FAQ 게시판
```

### ④ AI 강사님 행 (가장 중요)
```
[피드백 셀]
변경 전: 5단계 에이전트 격상
변경 후: 5단계 격상 + 바이브코딩 우려

[우리 대응 셀]
변경 전: T5 → SBERT → LLM 3차 피벗
변경 후: T5 → SBERT → LLM 3차 피벗 + 5단계 시스템 자체 설계
```

### ⑤ 하단 배너
```
변경 전: "해당 영역 운영 반영 완료 — 피드백을 듣는 것에 그치지 않고, 운영에 옮긴 팀"
변경 후: "5명 강사님 × 6회 멘토링 + 중간점검 서면 피드백 → 5개 영역 100% 운영 반영"
```

"AI 강사님 바이브코딩 지적 → 자체 IP 피벗" 스토리라인 완성

## 10. PowerPoint 슬라이드 이동 방법

### 방법 1: 드래그 앤 드롭 (가장 빠름)
1. 좌측 슬라이드 썸네일 패널에서 옮길 슬라이드 클릭
2. 마우스로 누른 채 원하는 위치로 끌어다 놓기

### 방법 2: 잘라내기 + 붙여넣기 (정확함)
1. 슬라이드 우클릭 → 잘라내기 (Ctrl+X)
2. 원하는 위치 슬라이드 사이를 클릭
3. 붙여넣기 (Ctrl+V)

### 방법 3: 여러 슬라이드 모드 (한눈에 보기)
- 상단 메뉴 보기 → 여러 슬라이드
- 큰 썸네일로 보면서 드래그
