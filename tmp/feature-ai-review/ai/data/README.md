## 📊 데이터 출처

- **자체 설문조사** (픽플리, n=100, 2026.04)
  - 부업 실패 경험자 대상 자기보고 설문
  - 응답자가 직접 작성한 회고 + 정량 데이터 (투자금/수익/기간/시간)
  - 8개 부업 카테고리 분포 (재능·프리랜서, 콘텐츠·SNS, 투자·재테크,
    온라인 판매·이커머스, 플랫폼 노동, 오프라인 부업, 디지털 상품, 기타)
- 개인정보 비식별화 처리 후 분석 활용
- AI 분석 시 원문 그대로 노출하지 않고 요약·재구성 후 활용
- MVP 단계 데이터이며, 정식 서비스 시 데이터 파트너십 / 추가 수집 예정

## 🔧 데이터 가공 이력

- **2026.04**: 픽플리 설문 100건 수집
- **2026.04.30**: 노션 마크다운 → CSV 변환, 단위 정제, 카테고리 표준화, 이상치 1건 보정 (#21: 1억→100만, 10억→1천만)
- **2026.04.30**: LLM 자동 태깅 (claude-sonnet-4-5)
  - keywords (3개), failure_category (6개 분류), summary (50자), risk_level (high/medium/low)
- **2026.04.30**: SBERT 임베딩 + FAISS 인덱스 구축
  - 모델: `jhgan/ko-sroberta-multitask` (한국어 특화)
  - 인덱스 위치: `recommender/sidepick_index.index`
- **2026.04.30**: 성공 가이드 매칭 테이블 49개 LLM 생성
  - 카테고리 7개 × 어려움 7개 = 49개
  - 톤: 경험 많은 부업 선배 (공감 + 단계별 액션)

## 📐 데이터 품질 기준

`failure_cases_100_tagged.csv`는 다음을 만족:

1. **자기보고 설문** — 응답자가 직접 작성한 부업 실패 회고
2. **정량 + 정성 데이터 결합** — 투자금/수익/기간 + 본문 서사
3. **카테고리 분류 완료** — 8개 표준 카테고리로 매핑
4. **LLM 자동 태깅 완료** — 분석/검색용 메타데이터 보강
