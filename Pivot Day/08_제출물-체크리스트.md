# 제출물 체크리스트

## 필수 제출물

### 1. 발표 영상 10분 이내

- 문제 정의 포함
- 핵심 기능 포함
- 실제 시연 포함
- 10분 이내 길이 확인
- 오디오, 화면 전환, 해상도 최종 확인

### 2. 발표 자료 PDF

- 최종 슬라이드 반영
- 오탈자 확인
- 데모 캡처 포함
- 마지막 장에 서비스 URL / GitHub 포함

### 3. 시연 영상 Demo

- 발표 영상 내 시연 구간 별도 추출
- 시작과 종료가 자연스러운지 확인
- 소리 유무 확인

### 4. GitHub Repository 링크

- `https://github.com/duvwlq/Sidepick`
- README 최신 상태 확인
- 발표와 저장소 설명 간 불일치 여부 확인

### 5. 퍼블릭 배포 URL

- `https://side-pick.app`
- `https://api.side-pick.app/api/health` 헬스체크 가능 여부 확인

## 선택 제출물

### 제출 권장

- 고도화 전략서
- 시스템 설계 / API 요약
- 스프린트 기록

### 제출 여유 있으면

- 베타 테스트 보고서
- Figma 화면 설계서

## 최종 점검 항목

1. 발표 메시지와 스탠스가 슬라이드, 영상, Q&A에서 일관되는가
2. 데모에 쓰는 URL과 화면이 실제 배포 상태와 일치하는가
3. 제출 파일명 규칙과 수정본 표기가 맞는가
4. 영상, PDF, 링크가 모두 열리는가
5. 현장 브리핑 1분과 Q&A 답변 톤이 과장 없이 일관되는가
