# 제출 패키지 가이드

이 문서는 실제 제출 파일을 어떤 이름으로 정리하고 어떤 순서로 점검할지 정리한 가이드입니다.

## 권장 폴더 구조

```text
Pivot Day/
├─ 제출용/
│  ├─ Sidepick_발표자료.pdf
│  ├─ Sidepick_발표영상.mp4
│  ├─ Sidepick_Demo.mp4
│  ├─ Sidepick_링크정리.txt
│  ├─ Sidepick_고도화전략서.pdf
│  └─ Sidepick_시스템설계요약.pdf
└─ 준비문서/
   ├─ 발표 대본
   ├─ 브리핑 원고
   ├─ Q&A 치트시트
   └─ 체크리스트
```

## 필수 제출 파일명 권장안

### 1. 발표 자료 PDF

- `Sidepick_발표자료.pdf`

### 2. 발표 영상

- `Sidepick_발표영상.mp4`

### 3. Demo 영상

- `Sidepick_Demo.mp4`

### 4. 링크 정리 파일

- `Sidepick_링크정리.txt`

내용:
- 서비스 URL
- API URL
- Health Check URL
- GitHub Repository

## 선택 제출 파일명 권장안

- `Sidepick_고도화전략서.pdf`
- `Sidepick_시스템설계요약.pdf`
- `Sidepick_스프린트기록.pdf`
- `Sidepick_베타테스트보고서.pdf`
- `Sidepick_UI설계서.pdf`

## 제출 직전 체크 순서

1. PDF가 열리는지 확인
2. 발표 영상이 10분 이내인지 확인
3. Demo 영상이 별도 파일로 저장됐는지 확인
4. GitHub 링크와 서비스 URL을 다시 열어보기
5. 파일명에 수정본 표기가 필요하면 규칙에 맞춰 반영하기

## 제출 직전 복사해서 쓸 링크 텍스트

서비스 URL: https://side-pick.app
