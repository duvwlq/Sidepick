# 제출 전 최종 30분 체크

1. 발표 자료 PDF 최종 저장
2. 발표 영상 최종 내보내기
3. Demo 영상 최종 내보내기

1. PDF 열림 확인
2. 영상 재생 확인
3. URL 2개 이상 실제 접속 확인
