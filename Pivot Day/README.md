## 권장 사용 순서

1. `02_발표-메시지-스탠스.md`로 메시지와 스탠스를 고정한다.
2. `05_발표자료-슬라이드-구성안.md`와 `10_슬라이드별-발표-멘트.md`로 PPT를 만든다.
3. `11_발표영상-10분-스크립트.md`로 발표 영상을 녹화한다.
4. `06_데모-시나리오.md`로 데모 동선을 점검한다.
5. `03_1분-스탠스-브리핑.md`와 `07_Red-Team-QA.md`로 현장 대응을 준비한다.
6. `14_슬라이드-문구-완성본.md`와 `15_제출용-링크-정리.md`를 제출 직전 복붙용으로 사용한다.
7. `17_발표자료-마스터-원고.md`를 기준으로 발표 자료 전체 흐름을 마지막 점검한다.
8. `19_1분-브리핑-최종-암기본.md`와 `20_제출-전-최종-30분-체크.md`를 발표 직전 사용한다.
