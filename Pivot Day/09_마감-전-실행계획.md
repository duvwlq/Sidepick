# 마감 전 실행 계획

## 기준

- 오늘: 2026년 6월 24일 수요일
- 최종 보완 제출 마감: 2026년 6월 25일 목요일 17:00
- 발표: 2026년 6월 26일 금요일 13:00~17:00

## 오늘 해야 할 일

### 1. 발표 구조 고정

- 발표 메시지 1줄 확정
- Persevere 선언 확정
- 1분 브리핑 암기본 작성
- 10분 발표 흐름 확정

### 2. 슬라이드 초안 완료

- 12~13장 구성으로 초안 작성
- 문제, 해결책, 데모, 차별점, 스탠스 반영
- 기술 구조도 1장 포함

### 3. 데모 경로 고정

- 메인 시나리오 URL 선정
- 백업 시나리오 준비
- 캡처 화면 확보

### 4. 제출물 초안 묶기

- 발표 영상 대본 정리
- PDF용 슬라이드 확정
- Demo 추출 구간 표시

## 내일 제출 마감 전 해야 할 일

### 오전

- 실제 발표 영상 녹화
- 데모 영상 별도 추출
- 슬라이드 PDF 내보내기

### 오후 15:00 전

- 링크 최종 점검
- 파일명 정리
- 수정본 여부 반영
- 제출물 업로드

### 오후 15:00~17:00

- 현장 1분 브리핑 반복 연습
- Red Team Q&A 20문항 반복 점검
- 최악 상황 대비 백업 캡처와 백업 멘트 준비

## 추천 시간 배분

1. 슬라이드/대본 35%
2. 데모 점검 25%
3. 영상 녹화/편집 25%
4. Q&A 대비 15%

## 절대 하지 말아야 할 것

1. 마감 직전 기능 추가
2. 실시간 AI 생성만 믿고 데모 구성
3. 없는 사용자 지표를 억지로 만들기
4. 기술 설명에 시간을 너무 많이 쓰기

## 최종 목표

제출물은 깔끔하게, 발표는 짧고 선명하게, Q&A는 솔직하지만 흔들리지 않게 가져간다.
