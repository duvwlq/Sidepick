# Sidepick 슬라이드 초단문 카피

PPT에 바로 붙여 넣기 좋은 가장 짧은 버전입니다.

## 1. 제목

- Sidepick
- AI 기반 부업 실패 분석 플랫폼
- 실패를 다음 선택의 데이터로

## 2. 문제

- 성공 후기는 많다
- 실패 학습 데이터는 적다
- 사용자는 같은 실수를 반복한다

## 3. 인사이트

- 사람들이 궁금한 건 성공보다 회피 포인트
- 실패는 의사결정 데이터가 될 수 있다

## 4. 해결책

- 실패 경험 구조화
- AI 분석
- 유사 사례 비교
- FAQ / 가이드 연결

## 5. 흐름

- 기록
- 분석
- 비교
- 학습
- 판단

## 6. 데모 1

- 사례 탐색
- 검색 / 필터
- 비슷한 실패 찾기

## 7. 데모 2

- 사례 상세
- 실패 원인 요약
- 다음 액션 제안

## 8. 데모 3

- 유사 사례 비교
- FAQ 연결
- 판단 도구로 전환

## 9. 기술

- React + Vite
- Spring Boot + MySQL
- FastAPI + Claude
- SBERT + FAISS
- Amplify + EC2 + RDS + Nginx

## 10. 차별점

- 실패를 데이터로 다룬다
- AI와 비교 흐름을 연결한다
- 읽는 서비스가 아니라 판단 도구다
