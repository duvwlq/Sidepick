# Sidepick Demo 녹화순서표

## 목표

- 2분 내외로 핵심 흐름만 보여주기

## 순서

1. 홈 또는 탐색 진입
2. 검색 / 카테고리 필터 사용
3. 특정 사례 상세 진입
4. AI 분석 리포트 확인
5. 유사 사례 확인
6. FAQ / 가이드 연결 확인

## 핵심 멘트

- 나와 비슷한 실패를 찾습니다
- AI가 실패 원인과 다음 액션을 정리합니다
- 한 사례가 아니라 패턴으로 비교합니다
- 실패를 다음 판단으로 연결합니다

## 길이 목표

- 90초 ~ 120초

## 백업

- 네트워크 지연 시 캡처 슬라이드 사용
- 메인 시나리오 1개만 고정
