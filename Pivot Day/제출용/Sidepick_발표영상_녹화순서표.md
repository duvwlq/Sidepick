# Sidepick 발표영상 녹화순서표

## 권장 녹화 순서

1. 오프닝 30초
2. 문제 정의 1분
3. 인사이트 / 해결책 1분
4. 데모 소개 20초
5. 탐색 화면 1분
6. 사례 상세 + AI 분석 2분
7. 유사 사례 + FAQ 1분
8. 기술 구조 1분
9. 차별점 / 스탠스 1분
10. 한계 / 다음 단계 / 마무리 1분

## 총 길이 목표

- 9분 내외
- 최대 10분 이내

## 녹화 방식

- 슬라이드 설명
- 데모 화면 전환
- 다시 슬라이드 복귀
- 마무리 멘트

## 끊어서 녹화할 때

- 파트 1: 문제 ~ 해결책
- 파트 2: 데모
- 파트 3: 기술 ~ 마무리

## 필수 확인

1. 오디오 레벨
2. 화면 해상도
3. 데모 전환 타이밍
4. 마지막 Persevere 선언
