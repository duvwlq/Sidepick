# Sidepick Demo 원고

이 파일은 `Sidepick_Demo.mp4` 별도 추출본을 만들 때 사용할 짧은 원고입니다.

## Demo 목표

- 실패 기록이 판단 도구로 바뀌는 흐름을 짧게 보여주기
- 실시간 생성보다 준비된 사례 상세 중심으로 안정적으로 시연하기

## Demo 흐름

### 1. 탐색 진입

- 홈 또는 탐색 화면 진입
- 검색 / 카테고리 흐름 소개
- 나와 비슷한 실패를 찾는 구조라고 설명

### 2. 사례 상세

- 특정 사례 상세 진입
- 실패 경험 본문 확인

### 3. AI 분석

- 실패 원인과 다음 액션 요약 확인
- “긴 후기를 더 빠르게 이해하게 만든다”는 멘트 사용

### 4. 유사 사례

- 유사 사례 비교 구간 확인
- “한 명의 실패가 아니라 패턴으로 읽게 만든다”는 멘트 사용

### 5. FAQ / 가이드

- 초보 사용자용 학습 동선 확인
- “읽고 끝나는 서비스가 아니라 다음 행동으로 연결된다”로 마무리

## Demo 종료 멘트

이렇게 Sidepick은 실패 경험을 단순히 저장하는 것이 아니라, 다음 선택의 판단 기준으로 바꾸는 흐름을 제공합니다.
