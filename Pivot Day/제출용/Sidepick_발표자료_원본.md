# Sidepick 발표자료 원본

이 파일은 PDF로 내보내기 전 PPT에 바로 옮길 수 있는 발표자료 원본입니다.

## 슬라이드 1

- 제목: Sidepick
- 부제: AI 기반 부업 실패 분석 플랫폼
- 한 줄: 실패담을 읽는 데서 끝나지 않고, 다음 선택의 데이터로 바꿉니다.

## 슬라이드 2

- 제목: 왜 실패 학습 플랫폼이 필요한가
- 부업 시장에는 성공 후기 콘텐츠가 과도하게 많다
- 실패 경험은 존재하지만 흩어져 있고 비교가 어렵다
- 사용자는 결국 같은 실수를 반복하기 쉽다

## 슬라이드 3

- 제목: 사람들이 진짜 궁금한 것
- 누가 성공했는가보다 내가 무엇을 피해야 하는가
- 실패 경험은 감정 소비형 콘텐츠가 아니라 의사결정 데이터가 될 수 있다

## 슬라이드 4

- 제목: Sidepick의 접근
- 실패 경험 구조화 등록
- AI 기반 실패 원인 및 다음 액션 분석
- 유사 사례 탐색
- FAQ / 가이드 연결

## 슬라이드 5

- 제목: 기록에서 판단까지
- 기록 → 분석 → 비교 → 학습 → 다음 실행 판단

## 슬라이드 6

- 제목: 탐색 - 나와 비슷한 실패 찾기
- 홈 / 탐색에서 사례 진입
- 검색 / 카테고리 기반 필터링
- 비교 가능한 실패 사례 탐색

## 슬라이드 7

- 제목: 상세 - 실패를 AI가 해석
- 사례 본문 확인
- 실패 원인과 다음 액션 요약
- 긴 후기를 더 빠르게 이해

## 슬라이드 8

- 제목: 비교와 학습으로 연결
- 유사 사례 비교
- FAQ / 가이드 연결
- 읽고 끝나는 서비스가 아니라 판단 도구

## 슬라이드 9

- 제목: 실제 구현 및 배포 구조
- Frontend: React + Vite
- Backend: Spring Boot + MySQL
- AI: FastAPI + Claude
- Similarity: SBERT + FAISS
- Infra: Amplify + EC2 + RDS + Nginx

## 슬라이드 10

- 제목: 우리가 다른 지점
- 실패 경험 자체를 구조화된 데이터로 다룬다
- AI 분석과 유사 사례를 한 흐름으로 연결한다
- 콘텐츠 소비가 아니라 판단 속도 단축에 집중한다

## 슬라이드 11

- 제목: 결론 - Persevere
- 문제 정의는 여전히 유효하다
- 핵심 사용자 루프는 이미 MVP로 구현됐다
- 지금 필요한 것은 Pivot이 아니라 사용자 검증과 고도화다

## 슬라이드 12

- 제목: 다음 단계에서 검증할 것
- 반복 사용성
- 시장성
- 수익 모델
- 데이터 신뢰도

## 슬라이드 13

- 제목: 실패를 다음 판단으로
- Sidepick은 실패를 저장하는 곳이 아니라, 실패를 다음 선택의 데이터로 바꾸는 도구입니다.
