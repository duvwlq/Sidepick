## 업로드 전 확인

1. 모든 파일이 실제로 열리는지 확인
2. 발표 영상이 10분 이내인지 확인
3. Demo 영상이 발표 영상과 별도 파일인지 확인
4. 파일명 규칙과 수정본 표기가 맞는지 확인

## 현재 상태 메모

- 발표 영상 길이: 약 88초
- Demo 영상 길이: 약 42초
