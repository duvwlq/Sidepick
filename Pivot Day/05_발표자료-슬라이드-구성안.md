# 발표자료 슬라이드 구성안

## 슬라이드 1. 제목

- 제목: Sidepick
- 부제: AI 기반 부업 실패 분석 플랫폼
- 한 줄: 실패담을 읽는 경험에서 끝나지 않고, 다음 선택의 데이터로 바꿉니다.

## 슬라이드 2. 문제

- 부업 시장에는 성공 후기만 많고 실패 학습 데이터는 부족
- 실패담은 흩어져 있고 검색 가능하지만 판단 가능하지 않음
- 사용자는 같은 실수를 반복할 가능성이 높음

## 슬라이드 3. 인사이트

- 사람들은 성공 사례보다 “무엇을 피해야 하는지”를 더 궁금해함
- 실패 경험은 감정 소비 콘텐츠가 아니라 의사결정 데이터가 될 수 있음

## 슬라이드 4. 해결책

- 실패 경험 구조화 등록
- AI 기반 실패 원인 및 다음 액션 분석
- 유사 사례 탐색
- FAQ / 가이드 연결

## 슬라이드 5. 핵심 사용자 흐름

- 기록
- 분석
- 비교
- 학습
- 다음 실행 판단

## 슬라이드 6. 데모 1

- 탐색 또는 홈 진입
- 사례 목록 탐색
- 사용자 관점에서 진입 동선 설명

## 슬라이드 7. 데모 2

- 사례 상세
- AI 분석 리포트
- 유사 사례 비교

## 슬라이드 8. 데모 3

- FAQ / 가이드 또는 작성 플로우
- “읽고 끝나는 서비스가 아님” 강조

## 슬라이드 9. 기술 구현

- React + Vite
- Spring Boot + MySQL
- FastAPI + Claude
- SBERT + FAISS
- Amplify + EC2 + RDS + Nginx

## 슬라이드 10. 차별점

- 실패를 구조화 데이터로 다룸
- 단순 콘텐츠가 아닌 탐색형 제품
- AI 분석과 유사 사례를 한 흐름에 연결

## 슬라이드 11. 스탠스

- 결론: Persevere
- 이유: 문제 정의 유효, 핵심 루프 구현, 다음 단계는 고도화

## 슬라이드 12. 한계와 다음 단계

- 사용자 검증 확대
- 재방문 구조 설계
- 수익화 가설 실험
- 데이터 신뢰도 강화

## 슬라이드 13. 마무리

- Sidepick은 실패를 저장하는 곳이 아니라 실패를 다음 판단으로 바꾸는 도구입니다.

## 디자인 메모

- 한 슬라이드에 문장 3개 이상 넣지 말 것
- 데모 슬라이드는 캡처 중심으로 구성
- 기술 슬라이드는 구조도 1장으로 압축
- 마지막 슬라이드는 스탠스와 한 줄 메시지를 다시 반복
