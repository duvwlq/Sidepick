## 디스코드 메시지 (복붙용)

```
[S3 보안 점검 요청 — MVP 심사 피드백 대응]

근원아, MVP 심사 피드백에서 "S3 항목 부분 확인, 경미한 보완 필요"가 짚혔어. 다음 라운드 전에 보안 체크리스트 5개 점검 + 캡처 부탁해.

[체크 1] HTTPS / SSL 인증서
- 배포 URL (https://...)에서 SSL 정상 적용 확인
- 브라우저 자물쇠 아이콘 캡처

[체크 2] .env / API 키 git 미업로드
- ai/.env, server/.env 등 .gitignore 등록 상태
- `git ls-files | grep -i env` 결과 캡처 (빈 결과면 OK)

[체크 3] DB 외부(Public) 접속 차단
- RDS 또는 MySQL 서버 보안 그룹 인바운드 룰
- VPC 내부만 접속 가능하게 설정됐는지 캡처

[체크 4] SSH(22) 포트 보안 그룹
- 0.0.0.0/0 (전체 공개) X
- 본인 IP만 허용 또는 Bastion 경유 캡처

[체크 5] ⚠️ 핵심 — S3 버킷 객체 목록 차단
- S3 버킷 루트 URL 직접 접속 (예: https://sidepick-bucket.s3.amazonaws.com/)
- 응답이 XML 파일 목록(ListBucketResult)이면 ❌
- AccessDenied 또는 PermissionDenied 응답이어야 ✅
- 캡처 + 정책 (Block Public Access 설정) 캡처

[정리]
체크 5개 결과를 `docs/보안-체크리스트-점검-결과.md` 같은 파일로 정리해서 push해주면, 다음 라운드 심사 자료에 첨부할게.

마감: 5/29(금) 밤까지 (베타테스트 1회 배포 직전 함께 확인하면 효율적)
우선순위: 🔴 P0
```

## 참고: 1주차 PDF의 보안 체크리스트 원문

> □ Secret 관리: GitHub에 API Key나 비밀번호가 업로드되지 않았음을 확인했습니까? (.gitignore 캡처)
> □ DB 보안: 데이터베이스는 외부(Public)에서 직접 접속이 불가능하게 설정되었습니까? (아키텍처 다이어그램에 명시)

> □ S3 등 객체 스토리지 루트 URL로 접속 시 저장된 파일 전체 목록(XML List)이 노출되지 않고 Access Denied가 뜨는지 확인했습니까? (캡처)
