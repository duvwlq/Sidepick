## 5. 충돌·주의사항 — 미리 알아두실 점

### 5-1. faqData.ts 형식 변화

**Before**:
```ts
answer:
  '먼저 사업자 등록부터 하시고...',
```

**After**:
```ts
answer: '**실전 Tip**\n1. 사업자 등록...\n2. 팔 상품을 1~2개...\n\n**실패 요인 TOP3**\n1. ...\n\n**주의사항**\n...',
```

- 모든 답변이 `\n` 이스케이프된 단일 따옴표 한 줄 형식
- TypeScript single-quote 문자열 정상 컴파일됨 (백틱 X)
- 검색·필터 로직은 그대로 작동 (답변 본문이 `\n` 포함 문자열이라 `.includes(query)` 검색 정상)

### 5-2. 답변에 큰따옴표 `"` 가 들어있는 항목 11건 있음

예: `"1년 후 똑같이 못 시작해도 OK?"` 같은 강조 표현.
- TypeScript single-quote 안에 `"` 는 escape 불필요 → 문자열로 안전하게 들어감
- 기존 FAISS 빌드 정규식이 이걸 잡지 못해서 11건 누락됐던 문제 fix 완료
- BE에서 만약 자체 파싱 코드가 있다면 같은 버그 있을 수 있으니 확인 부탁드려요

### 5-3. FaqPage.tsx 의존성

우리가 추가한 컴포넌트 (`SectionCard`, `NoteCard`, `ExpandedSections`, `parseAnswerSections`)는 모두 같은 파일 안에 inline 정의. 외부 의존성 추가 없음. import한 것은 기존부터 있던 것만:
- `react`, `react-router-dom`
- `Layout`, `SearchBar`, `HorizontalScroll` (기존 사용 중)
- `FAQ_CATEGORIES`, `FAQ_INTRO` (faqData.ts)

### 5-4. `digital-products` 카테고리 — 부업 분야로 처리

faqData.ts 의 카테고리 id 가 `digital-knowledge` 가 아닌 `digital-products` 이어서 변환 시 한 번 cross_topic 으로 잘못 처리됐다가 재변환했어요. **현재 247건 모두 카테고리별 올바른 3섹션 형식**. 혹시라도 BE 쪽에서 `digital-knowledge` 라는 id 를 어딘가에 하드코딩하셨다면 `digital-products` 로 일치시켜 주세요.
