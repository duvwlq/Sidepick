# Archive Docs

이 폴더는 과거 기록, 임시 메모, handoff, phase 문서, 구식 API 초안을 보관하는 용도입니다.

## Important

- 이 폴더 문서는 **최신 기준 문서가 아닙니다**.
- 현재 구현 판단은 반드시 [../README.md](../README.md)에 있는 공식 문서 인덱스를 기준으로 해야 합니다.
- archive 문서는 배경 맥락이나 과거 결정 이력을 볼 때만 참고합니다.

## Delete Candidates

이번 1차 정리에서는 삭제하지 않고 후보만 기록합니다.

- `docs/깃허브-저장소-링크.md`
  - 별도 문서 가치가 낮고, 루트 README 또는 docs 인덱스로 흡수 가능
- `ai/data/data_quality_report.md`
  - `ai/docs/data_quality_report.md`와 중복 가능성 높음
