# PM-11 — W5 가이드 페이지 콘텐츠 작성 우선순위

**작성일**: 2026-05-27
**작성자**: 오혜림 (팀장 / PM)
**티켓**: PM-11
**의존성**: PM-03 v1.4 (16개 카테고리 확장 + 횡단 주제 예시 2개)
**대상**: AI (W5 콘텐츠 작성 담당) / PD (가이드 페이지 디자인 참고)

---

## 1. 배경

PM-03 v1.2에서 카테고리가 7개 → 16개로 확장되면서 W5 콘텐츠 작성 분량이 **21~35개 → 32~48개**로 증가.
W5 진입 전 미리 작성 우선순위를 정해 시간 손실 최소화 + 가장 임팩트 높은 콘텐츠부터 채움.

---

## 2. 우선순위 3단계

### 1순위 (P0) — 부업 분야 7개 핵심 가이드 (각 1개씩 = 7개)

**목표**: 발표 시연용 핵심 카드. 사이드픽 메인 가치 (부업 분야 × 실패 사례 분석) 직접 보여주기.

| # | 카테고리 (slug) | 우선 주제 (1차 제목) | 1줄 요약 |
|---|---|---|---|
| 1 | `online-commerce` 온라인 판매·이커머스 | **스마트스토어 시작 전 체크리스트** | 위탁판매 vs 사입의 차이부터 초기 자금·시간 가이드까지 |
| 2 | `content-sns` 콘텐츠·SNS | **유튜브 부업 시작 전 체크리스트** | (PM-03 v1.2 예시 A 활용) — 구독자 1천 명까지 현실 가이드 |
| 3 | `digital-products` 디지털·지식판매 | **전자책으로 첫 수익 만드는 방법** | 주제 선정부터 PDF 제작·플랫폼 등록·홍보까지 |
| 4 | `platform-labor` 플랫폼 노동 | **배달 부업 시작 전 알아야 할 5가지** | 시급 계산·보험·세금·체력 관리 |
| 5 | `talent-freelance` 재능·프리랜서 | **크몽 프로필 첫 의뢰 받기 가이드** | 포트폴리오·단가 책정·첫 의뢰 응대 |
| 6 | `investment` 투자·재테크 | **부업 수익으로 시작하는 ETF 적립** | 단타 X, 장기 적립 위주 안전 가이드 |
| 7 | `offline-sidejob` 오프라인 부업 | **플리마켓 첫 부스 운영 가이드** | 자리세·재료비·재고·마케팅 |

### 2순위 (P1) — 횡단 주제 9개 핵심 가이드 (각 1개씩 = 9개)

**목표**: 부업 분야 카드와 챗봇 사이의 보완 영역. 사용자가 "내 분야"가 아닌 "공통 고민" 해소.

| # | 카테고리 (slug) | 우선 주제 (1차 제목) | 1줄 요약 |
|---|---|---|---|
| 8 | `before-start` 부업 시작 전 공통 | **부업 마인드셋 — 현실적 기대치 세우기** | 월 X만원에 대한 환상 깨고 시간·자본 vs 수익 매트릭스 |
| 9 | `tax-business` 세금·사업자 | **부업 시작 시 사업자 등록 가이드** | (PM-03 v1.2 예시 B 활용) — 간이 vs 일반 vs 면세 |
| 10 | `work-plus-sidejob` 본업 + 부업 | **회사 부업 금지 규정 확인 + 대응법** | 취업규칙 확인 / 동의 받기 / 비공개 운영 |
| 11 | `marketing` 마케팅·광고 운영 | **부업 첫 마케팅 — SNS vs 광고 어느 게 먼저?** | 무자본 SNS → 유료 광고 전환 시점 |
| 12 | `tools` 도구·툴 추천 | **부업 시작 시 꼭 깔아야 할 무료 툴 7가지** | 회계·일정·디자인·AI |
| 13 | `mental-care` 멘탈 관리·번아웃 | **부업 번아웃 회복 가이드** | (PM-03 v1.4 예시 C 활용) — 사인 인지 + 단계별 회복 |
| 14 | `legal-contract` 법률·계약 | **프리랜서 표준 계약서 핵심 5가지** | 외주 단가·납기·저작권·환불 조항 |
| 15 | `accounting` 회계·장부 | **부업 통장 분리 + 영수증 관리 기초** | 비용 처리·세금계산서·세무 SaaS |
| 16 | `insight` 부업 인사이트 | **2026년 부업 트렌드 — 떠오르는 분야 vs 정체 분야** | 시장 흐름·신규 진입 전략 |

### 3순위 (P2) — 보강 가이드 (시간 여유 따라 16~32개)

**목표**: 각 카테고리당 2~3개 추가 가이드. 검색 SEO + 깊이 확보.

#### 부업 분야별 보강 (총 16개)

| 카테고리 | 보강 주제 (각 카테고리 2~3개) |
|---|---|
| `online-commerce` | 쿠팡 위탁판매 vs 11번가 / 위탁판매 사기 패턴 / 상위 노출 키워드 기초 |
| `content-sns` | 인스타 부업 — 팔로워 1천 명까지 / 블로그 애드포스트 vs 애드센스 / 틱톡·릴스 수익화 |
| `digital-products` | 온라인 강의 첫 강좌 만들기 / 노션 템플릿 판매 / 사진·이미지 라이선스 |
| `platform-labor` | 쿠팡 플렉스 vs 배민 커넥트 비교 / 대리운전 첫 콜 받기 |
| `talent-freelance` | 숨고 vs 탈잉 비교 / 외주 단가 책정법 |
| `investment` | 코인 적립 — 단타 차단 가이드 / 부동산 소액 투자 (P2P 주의사항) |
| `offline-sidejob` | 공방 시작 자본 가이드 / 핸드메이드 vs 사입 |

#### 횡단 주제 보강 (총 16개)

| 카테고리 | 보강 주제 (각 카테고리 1~2개) |
|---|---|
| `before-start` | 적성·시간·자본 매칭 진단 / 본업 종류별 부업 추천 |
| `tax-business` | 종합소득세 신고 가이드 / 통신판매업 신고 |
| `work-plus-sidejob` | 시간 분배 전략 (주 단위 / 일 단위) |
| `marketing` | 광고비 효율 측정 / 인플루언서 협업 첫 단계 |
| `tools` | AI 도구 활용 (ChatGPT·Claude) / 회계 SaaS 비교 |
| `mental-care` | 동기 부여 유지 전략 / 스트레스 관리 루틴 |
| `legal-contract` | 저작권·상표권 기초 / 분쟁 해결 (소액 분쟁 조정) |
| `accounting` | 종합소득세 신고 — 부업 소득 합산 / 부가가치세 신고 |

## 3. 작성 가이드 (PM-03 v1.4 섹션 6 참조)

- **톤**: 객관적 + 따뜻한 / 단정적 표현 금지
- **길이**: 본문 1000~1500자 / 항목 3~7개 / 각 항목 30~60자
- **출처 명시 필수**
- **부업 분야 카드**: `failure_factors` / `success_lessons` / `recommended_*` 필드 활용
- **횡단 주제 카드**: `procedure_steps` / `faq` / `legal_disclaimer` 필드 활용

## 4. W5 작업 분량 추정

| 우선순위 | 건수 | 시간 추정 (1건당 30~45분) |
|---|---|---|
| **P0** (부업 분야 7개) | 7 | 3.5~5h |
| **P1** (횡단 주제 9개) | 9 | 4.5~7h |
| **P2** (보강 32개) | 32 | 16~24h |
| **합계** | **48** | **24~36h** |

→ **W5 1주(7일) 풀타임 작업** 기준 P0 + P1 (16개)는 확실히 완성 가능. P2는 시간 여유에 따라.
