### 5.1 핵심 인사이트

**환각율 44% 표면 FAIL이지만, 진짜 환각이 아님**:

1. **case_id 인용 오류 0건** — Sonnet이 FAISS 검색 결과 외 case_id를 만들어내지 않음 ✅
2. **카테고리 화이트리스트 위반 0건** — failure_category 7종 enum 안에서만 분류 ✅
3. **22건 모두 "키워드 본문 매칭 0%"** ← 진짜 원인

근본 원인:
- 테스트 시나리오 = `test_scenarios_50.csv` = AI-19 재라벨링 이전 데이터
- 본문이 **광고/홍보글 / 메타정보 / 노이즈** 다수 (AI-19에서 광고 43%, 메타 15%, neutral 5% = 합 63% 제거 확인됨)

- → "사용자 본문에 매칭 안 됨"으로 환각 플래그

**즉, 안전장치는 Sonnet 환각을 완벽히 차단했지만, 측정 자체가 부정확.**
