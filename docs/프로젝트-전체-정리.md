# 프로젝트 전체 정리

## 1. 프로젝트 개요

Sidepick은 부업과 사이드 프로젝트 실패 경험을 구조화해서 기록하고, 유사 사례 탐색과 AI 분석을 통해 다음 의사결정의 리스크를 줄이는 것을 목표로 하는 MVP 프로젝트입니다.

현재 운영 방향은 다음과 같습니다.

- 인증은 카카오 로그인 중심
- 실패 경험 등록 / 조회 / 수정 / 삭제 지원
- 유사 사례 탐색과 AI 분석 결과 제공
- 프론트는 Amplify, 백엔드는 EC2 + Docker Compose + RDS + Nginx 구조

## 2. 브랜치 구조

- `main`: 기준 브랜치
- `feature/backend`: 백엔드 작업 브랜치
- `feature/ai`: AI 작업 브랜치
- `feature/fe-setup`: 프론트 작업 브랜치
- `Sidepick-merge-branch`: 통합 및 배포 브랜치

현재 운영 배포 기준 브랜치는 `Sidepick-merge-branch`입니다.

## 3. 백엔드 정리

### 기술 스택

- Java 17
- Spring Boot 3
- Spring Security
- Spring Data JPA
- MySQL
- JWT
- OAuth

### 구현된 기능

- 이메일 회원가입 / 로그인 API
- 이메일 인증 코드 발급 / 확인 API
- 카카오 로그인 API
- 구글 로그인 API
- `/users/me` 기반 사용자 정보 조회
- 경험 등록 / 목록 / 상세 / 수정 / 삭제 API
- AI 분석 생성 / 조회 API

### 운영 인증 정책

- `APP_AUTH_LOCAL_ENABLED`
- `APP_AUTH_KAKAO_ENABLED`
- `APP_AUTH_GOOGLE_ENABLED`

현재 운영 권장값:

- 로컬 로그인 비활성
- 카카오 로그인 활성
- 구글 로그인 비활성

### 백엔드 개선 작업

- 인증 제공자 설정 기반 제어 추가
- 인증 서비스 책임 분리
- 경험 목록 검색 / 정렬 / 필터 강화
- 경험 등록 검증 강화
- 통합 테스트 보강

## 4. 프론트엔드 정리

### 기술 스택

- React
- TypeScript
- Vite
- Tailwind CSS

### 구현된 화면

- 메인 홈
- 인증 진입 화면
- 카카오 로그인 콜백
- 사례 탐색
- 경험 작성 4단계
- 경험 상세
- 마이페이지

- 운영에서는 카카오 로그인 중심 UI
- 이메일 로그인 / 회원가입은 준비 중으로 노출 제한
- 탐색과 결과 확인 중심 UX 강화

## 5. AI 파트 정리

- 경험 데이터 기반 분석 구조 설계
- 백엔드와 연동 가능한 분석 API 흐름 확보
- 유사 사례 탐색과 실패 요인 추출 방향 검토

남은 작업:

- 분석 결과 표현 강화
- 비동기 분석 처리 검토
- 실패 시 재시도 / 예외 처리 보강

## 6. 운영 / 인프라 정리

- AWS Amplify
- 운영 도메인:
  - `https://side-pick.app`
  - `https://www.side-pick.app`

### 백엔드

- AWS EC2
- Docker Compose 실행
- Nginx 프록시
- HTTPS 적용
- 운영 API:
  - `https://api.side-pick.app/api`

- AWS RDS MySQL

## 7. 포트폴리오 포인트

- JWT + `/users/me` 기반 인증 구조 설계
- 카카오 OAuth 로그인 직접 연동
- 경험 데이터 구조화 및 검증 로직 설계
- 검색 / 정렬 / 필터 API 강화
- Docker 기반 운영 배포 구성
- Amplify / EC2 / RDS / Nginx / HTTPS 직접 연결

## 8. 발표 포인트

### 문제 정의

- 실패 경험은 많지만, 구조화된 데이터와 재활용 가능한 인사이트는 부족하다.

### 해결 방향

- 실패 경험을 구조화해서 기록한다.
- 유사 사례를 탐색할 수 있게 한다.
- AI 분석으로 실패 요인과 다음 리스크를 해석한다.

### 구현 포인트

- 카카오 중심 인증
- 실패 경험 CRUD
- 탐색 / 상세 / AI 분석 결과
- 실제 클라우드 배포

## 9. 남은 작업

- 카카오 운영 로그인 최종 점검
- 이메일 인증 운영 반영 여부 결정
- 좋아요 / 북마크 API
- 검색 / 필터 고도화
- AI 결과 화면 강화
- 프론트 피그마 일치도 개선
