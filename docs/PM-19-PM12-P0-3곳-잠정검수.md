## 3. 통합 시 점검할 외부 의존 항목 (BE/PD/FE 도착 후)

### 3.1 BE 응답 형식

- `POST /api/analyze` 응답에 `analysis.explanation = AnalysisExplanation` 형식 일치 여부
- `GET /api/similar/{id}` 응답에 `cases[].explanation = SimilarCaseExplanation` 형식 일치 여부
- `GET /api/stats/failure-pattern?category={slug}` 응답에 `explanation = StatsExplanation` 추가 가능 여부

### 3.2 PD 디자인

- "?" 아이콘 위치 3곳 (분석 / 유사사례 / 통계 그래프)
- 모달/툴팁 UI (모바일 전체 폭 / 데스크탑 400~520px)
- `sufficient_data: false`일 때 "데이터 수집 중" 안내 카드와 통계 explanation 모달의 시각적 위계 정합

### 3.3 FE 통합

- Radix UI Tooltip 또는 자체 모달 컴포넌트
- `_debug` 필드 모달에 노출하지 않는지 검증 (관리자 모드 X)
- `confidence` / `similarity` 0~1 float → % 변환 (반올림)
