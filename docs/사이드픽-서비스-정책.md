## 1. 서비스 제공 범위

사이드픽 콘텐츠는 **2개 층**으로 구성됩니다.

| 층 | 정의 | 콘텐츠 형태 | 에이전트 C 통계 분석 |
|---|---|---|---|
| **부업 분야 7개** | "무슨 부업을 하느냐" — 택1 분야 | 사례 검색 + 통계 + 가이드 | ✅ **분석 대상** |
| **횡단 가이드 주제 9개** | "부업하면서 공통으로 마주치는 일" — 모두에게 해당 | 가이드 콘텐츠만 | ❌ (통계 X, 가이드만) |

→ **에이전트 C(챗봇)의 통계·검색 분석 대상은 부업 분야 7개**입니다. 횡단 주제 9개는 부업 가이드 페이지의 콘텐츠로만 노출됩니다.

### 1-1. 분석 대상 7개 부업 분야 (에이전트 C 통계·사례 분석 대상)

| # | 카테고리 | 포함 분야 |
|---|---|---|
| 1 | **온라인 판매·이커머스** | 스마트스토어 / 쿠팡 위탁판매 / 11번가·G마켓 / 자사몰 / 해외 직구·구매대행 |
| 2 | **콘텐츠·SNS** | 유튜브 / 인스타그램 / 블로그 / 틱톡·릴스 / 트위치·아프리카TV |
| 3 | **디지털·지식판매** | 전자책 / 온라인 강의 / 템플릿·디자인 자산 / 음원·이미지 라이선스 |
| 4 | **플랫폼 노동** | 배달 알바 / 대리운전 / 쿠팡 플렉스 / 가사 도우미 |
| 5 | **재능·프리랜서** | 크몽·숨고·탈잉 / 외주 디자인·개발 / 과외·튜터링 / 번역·통역 |
| 6 | **투자·재테크** | 주식 장기 투자 / 코인 / 부동산 소액 / P2P 투자 / 채권·ETF |
| 7 | **오프라인 부업** | 공유 오피스 운영 / 플리마켓·핸드메이드 / 카페·소품샵 / 오프라인 클래스 |

> 📌 `ALLOWED_CATEGORIES` enum (AI-04 시스템 프롬프트 / AI-05 환각 방지 룰 / BE-06 가드레일)은 위 7개로 정의됩니다.

### 1-2. 횡단 가이드 주제 9개 (부업 가이드 페이지 콘텐츠 전용)

부업 분야와 무관하게 모든 부업자가 공통으로 마주치는 주제입니다. **에이전트 C 통계 분석 대상이 아니며**, 부업 가이드 페이지에서 가이드 카드 형태로만 제공됩니다.

| # | 카테고리 | 포함 주제 |
|---|---|---|
| 8 | **부업 시작전 공통** | 마인드셋 / 부업 종류 선택법 / 시간 관리 기초 / 본업과의 관계 |
| 9 | **세금·사업자** | 사업자 등록 / 종합소득세 / 부가가치세 / 원천세 / 4대 보험 |
| 10 | **본업+부업** | 시간 분배 / 본업 회사 정책 / 부업 금지 대응 / 워라밸 |
| 11 | **마케팅·광고 운영** | SNS 마케팅 / 광고 채널 선택 / 콘텐츠 마케팅 / 인플루언서 협업 |
| 12 | **도구·툴 추천** | 부업 관리 앱 / 회계 도구 / 디자인 도구 / AI 도구 활용 |
| 13 | **멘탈관리·번아웃** | 번아웃 사인 / 회복 방법 / 동기 부여 / 스트레스 관리 |
| 14 | **법률·계약** | 표준 계약서 / 저작권·상표권 / 개인정보보호 / 분쟁 해결 |
| 15 | **회계·장부** | 수입·지출 관리 / 소득 신고 / 영수증 관리 / 세금계산서 |
| 16 | **부업 인사이트** | 트렌드 분석 / 성공 사례 분석 / 실패 패턴 / 시장 변화 |

> 📌 횡단 주제는 `GUIDE_CATEGORIES` 별도 enum으로 관리 (가이드 페이지 BE/FE에서만 사용). 에이전트 C 검증 enum에는 포함되지 않습니다.

### 1-3. 서비스 제공 항목
- 실패 사례 검색 + AI 분석 가이드 제공 (분야 7개 대상)
- 유사 실패 사례 매칭 (SBERT + FAISS 기반)
- 업종별 통계 + 실패 요인 TOP3 (분야 7개 대상)
- 부업 시작 전 실패 조심 안내
- 부업 가이드 (16개 카테고리 — 분야 7개 + 횡단 주제 9개)

## 2. 카테고리 외 질문 처리 방침

### 2-1. 정의
에이전트 C(챗봇)는 **분석 대상 7개 부업 분야**에 대해서만 사례·통계 분석을 제공합니다. 다음과 같은 질문은 챗봇 응답 범위 외입니다:

- 정치·연예·일반 시사 질문
- 의료·법률·세무·금융 자문
- 부업과 무관한 일반 지식 질의
- 부업이지만 7개 분석 분야 외 (예: 농업·축산업·수산업 등)

> 📌 **횡단 주제 9개(세금·법률·멘탈관리 등)는 가이드 페이지 콘텐츠에는 있지만, 에이전트 C 챗봇은 해당 질문에 대해서도 사례 데이터가 없으므로 "가이드 페이지에서 확인하시는 게 좋아요" 형태로 가이드 페이지를 안내합니다.**

### 2-2. 응답 방침

**Case 1) 7개 분석 분야 외 부업 질문 (예: 농업)**:
```
"사이드픽은 7개 부업 분야(온라인 판매·이커머스 / 콘텐츠·SNS / 디지털·지식판매 / 플랫폼 노동 / 재능·프리랜서 / 투자·재테크 / 오프라인 부업)에 대한 사례·통계 분석을 제공해요. 농업·축산업·수산업 등은 v2에서 확장 예정이에요.

[출처: 사이드픽 서비스 정책]"
```

**Case 2) 횡단 주제 질문 (예: "사업자 등록 어떻게 해요?")**:
```
"사업자 등록은 부업 가이드 페이지의 '세금·사업자' 카테고리에서 자세히 확인하실 수 있어요. 챗봇은 부업 분야별 사례·통계 분석을 도와드려요. 어떤 부업 분야가 궁금하세요?

[안내: 가이드 페이지 안내]"
```

**Case 3) 부업과 무관한 일반 질문**:
```
"사이드픽은 부업 정보 분석 서비스예요. 부업 관련해서 궁금한 점이 있으시면 알려주세요.

[출처: 사이드픽 서비스 정책]"
```

### 2-3. 위험 카테고리 차단 (별도 안전 정책 참조)
주식 단타 / 코인 단타 / 도박성 투자 / 미등록 다단계 등 위험 추천은 본 정책이 아닌 **사이드픽 안전 정책** 참조 (`docs/사이드픽-안전-정책.md`).

## 3. v2 확장 계획 (참고)

### 3-1. 부업 분야 확장 (분석 대상 7개 → ?)
- 농업·축산업·수산업 (오프라인 부업의 농촌형 추가)
- 글로벌 부업 (해외 사이트 활용)
- 직장인 N잡 매니징 (시간 관리 도구 등)

### 3-2. 횡단 주제 확장 (가이드 9개 → ?)
사용자 검색 데이터·문의 누적 분석 결과에 따라 다음 카테고리 추가 검토:
- **비자·해외 부업** (해외 거주자의 한국 부업 / 한국인의 해외 부업)
- **부업 자동화** (AI·노코드 툴로 부업 자동화)
- **부업 매각·승계** (운영 중인 부업 매각 / 동업자 변경)
- **공동 부업** (가족·친구와 공동 운영 시 지분·정산)
- **개인 브랜딩** (퍼스널 브랜드 구축 — 마케팅·콘텐츠와 별개로)

### 3-3. 확장 의사결정 기준
- v2 확장은 **사용자 데이터 누적 + 시장 수요 확인 후 결정**
- 부업 분야 확장 시 `ALLOWED_CATEGORIES` enum / `business_categories` 테이블 / 통계 페이지 모두 영향 → BE 협의 필수
- 횡단 주제 확장 시 `GUIDE_CATEGORIES` enum + 가이드 콘텐츠만 추가 (분석 시스템 영향 없음)
