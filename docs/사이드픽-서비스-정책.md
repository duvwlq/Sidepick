## 1. 서비스 제공 범위

### 1-1. 사이드픽이 분석하는 7개 부업 카테고리

| # | 카테고리 | 포함 분야 |
|---|---|---|
| 1 | **온라인 판매·이커머스** | 스마트스토어 / 쿠팡 위탁판매 / 11번가·G마켓 / 자사몰 / 해외 직구·구매대행 |
| 2 | **콘텐츠·SNS** | 유튜브 / 인스타그램 / 블로그 / 틱톡·릴스 / 트위치·아프리카TV |
| 3 | **디지털 상품·지식** | 전자책 / 온라인 강의 / 템플릿·디자인 자산 / 음원·이미지 라이선스 |
| 4 | **플랫폼 노동** | 배달 알바 / 대리운전 / 쿠팡 플렉스 / 가사 도우미 |
| 5 | **재능·프리랜서** | 크몽·숨고·탈잉 / 외주 디자인·개발 / 과외·튜터링 / 번역·통역 |
| 6 | **투자·재테크** | 주식 장기 투자 / 코인 / 부동산 소액 / P2P 투자 / 채권·ETF |
| 7 | **오프라인 부업** | 공유 오피스 운영 / 플리마켓·핸드메이드 / 카페·소품샵 / 오프라인 클래스 |

### 1-2. 서비스 제공 항목
- 실패 사례 검색 + AI 분석 가이드 제공
- 유사 실패 사례 매칭 (SBERT + FAISS 기반)
- 업종별 통계 + 실패 요인 TOP3
- 부업 시작 전 실패 조심 안내
- 부업 가이드 (기본 정보 + 체크리스트)

## 2. 카테고리 외 질문 처리 방침

### 2-1. 정의
사이드픽은 위 7개 부업 카테고리에 대한 분석만 제공합니다. 다음과 같은 질문은 서비스 범위 외입니다:

- 정치·연예·일반 시사 질문
- 의료·법률·세무·금융 자문
- 부업과 무관한 일반 지식 질의
- 부업이지만 7개 카테고리 외 (예: 농업·축산업·수산업 등)

### 2-2. 응답 방침
카테고리 외 질문 감지 시:
```
"사이드픽은 7개 부업 카테고리에 대한 분석만 제공해요. 다른 분야는 v2에서 확장 예정이에요.

7개 카테고리 안에서 관심 있는 분야가 있으시면 알려주세요:
1) 온라인 판매·이커머스
2) 콘텐츠·SNS
3) 디지털 상품·지식
4) 플랫폼 노동
5) 재능·프리랜서
6) 투자·재테크
7) 오프라인 부업

[출처: 사이드픽 서비스 정책]"
```

### 2-3. 위험 카테고리 차단 (별도 안전 정책 참조)
주식 단타 / 코인 단타 / 도박성 투자 / 미등록 다단계 등 위험 추천은 본 정책이 아닌 **사이드픽 안전 정책** 참조 (`docs/사이드픽-안전-정책.md`).
