## 1. 위험 차단 키워드 리스트

다음 키워드 감지 시 에이전트 C는 사례 검색 없이 즉시 차단 응답을 제공합니다.

- 일확천금 / 떼돈 / 쉽게 버는 돈

### 1-5. 사기 의심 행위

## 2. 차단 응답 방침

### 2-1. 위험 키워드 감지 시 응답
```
"사이드픽은 안전한 부업 정보만 제공해요.
단기 수익 보장 / 위험 투자 / 사기 의심 부업 같은 분야는 다루지 않아요.

대신 사이드픽이 분석하는 7개 부업 카테고리에서 안전하게 시작할 수 있는 부업을 추천해드릴게요.
관심 있으신 분야 알려주시면 비슷한 사례 + 통계를 보여드릴게요.

[출처: 사이드픽 안전 정책]"
```

### 2-2. 사례 검색 차단
위험 키워드 감지 시 **search_cases / query_stats 호출 X**. 즉시 차단 응답 반환.

### 2-3. 부분 매칭 처리
- "주식 단타" → 차단 (단타 키워드)
- "주식 장기 투자" → 정상 (투자·재테크 카테고리)
- "코인 단타" → 차단
- "코인 장기 투자" → 정상 (사용자 책임 하 답변, 위험 안내 포함)
- "유튜브 한 방에 성공" → 차단 (한 방 키워드)
- "유튜브 부업 어떻게?" → 정상

## 3. 사기 부업 식별 가이드 (사용자 안전 가이드)

### 3-1. 사기 부업의 일반적 특징
1. **선입금·보증금 요구**: 정상 부업은 입금부터 안 시킴
2. **수익 보장 약속**: 100% 수익은 사기
3. **빠른 수익**: "1주일 만에 100만원" 같은 약속
4. **인맥 강요**: 지인 영입을 수익화 조건으로
5. **정보 비공개**: 가입 후에야 알려주는 비즈니스 모델

### 3-2. 안전 부업 체크리스트
- ✅ 시작 전 정보 공개 (수익 구조 / 비용 / 시간 투자)
- ✅ 입금·보증금 없음
- ✅ 등록 사업자 / 공식 플랫폼 (스마트스토어 / 쿠팡 / 유튜브 등)
- ✅ 단계적 성장 (1년 이상 지속 가능성)
- ✅ 본인 책임 하 진행 (강요·압박 없음)

### 3-3. 의심 시 행동 가이드
- 한국소비자원 (1372) 문의
- 금융감독원 불법 사금융 신고 센터 (1332)
- 경찰청 사이버수사대 (182)
