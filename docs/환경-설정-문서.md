# 환경 설정 문서

## 개요

현재 로컬 개발 기준은 다음과 같습니다.

- 프론트엔드: `fe/`에서 Vite 실행
- 백엔드/DB/AI: `infra/docker-compose.yml` 기준 Docker Compose 실행
- 백엔드 포트: `8081`
- AI 서버 포트: `8001`

상세 개요는 [README.md](/D:/Codex_Folder/Sidepick/README.md) 를 우선 기준으로 봅니다.

## 로컬 실행 절차

### 1. 환경 변수 파일 생성

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

### 2. 백엔드 스택 실행

Windows PowerShell:

```powershell
.\scripts\dev-up.ps1
```

macOS / Linux:

```bash
./scripts/dev-up.sh
```

또는 직접 실행:

```bash
docker compose -f infra/docker-compose.yml up -d --build
```

### 3. 프론트엔드 실행

```bash
cd fe
npm install
npm run dev
```

### 4. 빌드 확인

Windows PowerShell:

```powershell
.\mvnw.cmd -DskipTests package
```

macOS / Linux / Git Bash:

```bash
chmod +x ./mvnw
./mvnw -DskipTests package
```

### 5. 실행 확인

- 백엔드 헬스 체크: `http://localhost:8081/api/health`
- 백엔드 Swagger UI: `http://localhost:8081/swagger-ui.html`
- AI 서버 헬스 체크: `http://localhost:8001/health`

프론트 개발 서버 포트는 Vite 기본값을 따르며, 백엔드 CORS 기본 허용값에는 `4173`, `4174`, `5173` 이 포함되어 있습니다.
