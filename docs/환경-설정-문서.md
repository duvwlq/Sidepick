# 환경 설정 문서

## 개요

이 프로젝트는 MySQL, Spring Boot, Docker Compose 기준으로 실행되며,
기본적인 실행 절차는 `README.md`에 정리되어 있습니다.

## 로컬 실행 절차

### 1. 환경 변수 파일 생성

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

### 2. Docker 실행

Windows PowerShell:

```powershell
.\scripts\dev-up.ps1
```

macOS / Linux:

```bash
./scripts/dev-up.sh
```

또는 직접 실행:

```bash
docker compose -f infra/docker-compose.yml up -d --build
```

### 3. 빌드 확인

Windows PowerShell:

```powershell
.\mvnw.cmd -DskipTests package
```

macOS / Linux / Git Bash:

```bash
chmod +x ./mvnw
./mvnw -DskipTests package
```

### 4. 실행 확인

- 애플리케이션: `http://localhost:8081`
- 헬스 체크: `http://localhost:8081/api/health`
- Swagger UI: `http://localhost:8081/swagger-ui.html`
