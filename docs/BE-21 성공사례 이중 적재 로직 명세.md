# BE-21 성공사례 이중 적재 로직 명세

## 목적

성공사례를 실패사례와 분리된 별도 인덱스로 운영하지 않고, 동일한 FAISS 통합 인덱스에 적재하되 `type` 메타데이터로 구분한다.  
이 방식은 PM-04 Tool 명세의 `search_cases(query, type, limit=3)` 계약과 맞춘다.

## 적재 원칙

1. 실패사례와 성공사례는 동일한 임베딩 모델, 동일한 벡터 차원, 동일한 인덱스에 저장한다.
2. 검색 시 필터링 기준은 문서 메타데이터의 `type` 값이다.
3. `type` 허용 값은 아래 2개로 고정한다.
   - `failure`
   - `success`
4. Agent C는 `search_cases(..., type="success")` 호출로 성공사례만 조회한다.

## 공통 문서 스키마

성공사례와 실패사례 모두 아래 필드를 공통 메타데이터로 가진다.

| 필드 | 설명 |
| --- | --- |
| `case_id` | 원본 사례 식별자 |
| `type` | `failure` 또는 `success` |
| `category` | 7개 분석 카테고리 중 하나 |
| `original_text` | 원문 |
| `duration_months` | 활동 기간 |
| `investment_amount` | 투자금 |
| `keywords` | 핵심 키워드 배열 |
| `ai_analysis` | AI 요약/분석 결과 |
| `meta_grid` | 구조화된 비교용 메타데이터 |

추가 필드는 유형별로 분기한다.

- 실패사례 전용
  - `failure_patterns`
  - `key_issues`
- 성공사례 전용
  - `success_factors`
  - `difference_from_user`

## 적재 흐름

1. DB 또는 수집 파이프라인에서 성공사례 row를 읽는다.
2. Agent C 공통 스키마로 정규화한다.
3. 메타데이터에 `type="success"`를 주입한다.
4. 실패사례와 동일한 임베딩 함수를 적용한다.
5. 기존 FAISS 통합 인덱스에 upsert 한다.
6. 문서 저장소에도 동일한 `case_id` 기준으로 메타데이터를 함께 저장한다.

## 업데이트 주기

- 기본 배치 주기: 5분
- 최대 허용 주기: 10분
- 운영 초기에 성공사례 유입량이 작으면 10분 주기로 시작하고, 증가 시 5분으로 조정한다.

## 자동 업데이트 트리거

아래 이벤트가 발생하면 성공사례 인덱스 업데이트 작업을 큐에 넣는다.

1. 성공사례 신규 생성
2. 성공사례 수정
3. 성공사례 삭제 또는 비공개 전환
4. 카테고리 재분류
5. AI 후처리 필드(`keywords`, `ai_analysis`, `success_factors`) 재생성

트리거 후 처리 규칙:

- 생성/수정: 해당 `case_id` 문서를 재임베딩 후 upsert
- 삭제/비공개: 해당 `case_id` 문서를 인덱스와 메타 저장소에서 제거
- 재분류: 기존 문서 제거 후 새 메타데이터로 재적재

## 검색 계약

`search_cases(query, type, limit=3)` 구현 시 다음을 보장한다.

1. `type` 미지정 시 기본값은 `failure`
2. `type="success"`면 성공사례만 반환
3. 반환 결과의 `case_id`는 가드레일 검증 가능한 원본 식별자를 유지
4. `category`는 7개 분석 카테고리만 허용

## 운영 로그 권장 필드

- `job_type=index_sync`
- `case_type=success`
- `case_id`
- `event=create|update|delete|reclassify`
- `embedding_version`
- `index_version`
- `duration_ms`
- `result=success|retry|failed`

## 확인 포인트

- 성공/실패 인덱스를 분리하지 않으므로 검색 코드가 `type` 필터를 누락하면 오검색이 발생한다.
- `case_id`는 가드레일 검증과 연결되므로 적재 전후 값이 바뀌면 안 된다.
- 성공사례도 실패사례와 동일한 카테고리 enum을 사용해야 통계/추천/가드레일 계약이 유지된다.
