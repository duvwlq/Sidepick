## 1. 페이지 목적 — 왜 부업 가이드 페이지?

### MVP 학습
- **사이드픽은 실패 사례 분석 + AI 가이드 중심**
- 사용자가 "기본적인 정보"는 어디서 얻나? → MVP에서는 부재
- PD 강사님: **"솔루션이 아닌 기본 툴"** 컨셉 제안 — 사용자가 부업 시작 전에 참고할 수 있는 기본 정보 제공

### 고도화 방향
- **부업 시작 전 / 중 / 후에 참고할 수 있는 가이드** 제공
- 검색 가능한 구조 (사용자가 원하는 정보 빠르게 찾기)
- 사이드픽 사례 검색과 연결 (선순환)

### 사용자 시나리오
```
1. 사용자가 "유튜브 부업 시작해볼까?" 고민
   → 부업 가이드 페이지 검색 "유튜브"
   → 유튜브 부업 가이드 카드 노출 (시작 전 체크리스트 / 주요 실패 요인 등)
   → 사이드픽 사례 검색으로 연결 ("유튜브 실패 사례 보기")
```

## 2. 페이지 구성 — 3개 영역

### 영역 1: 검색창 + 카테고리 칩 (상단)
- 검색창 (placeholder: "어떤 부업 정보를 찾으세요?")

- 가이드 카드 = 1개 가이드라인 단위

### 영역 3: 사이드픽 사례 연결 (하단)
- "관련 실패 사례 보기" 버튼
- 사이드픽 사례 검색 페이지로 이동

## 4. 가이드라인 포맷 — 필드 구조

### 가이드 카드 필드 정의

```typescript
interface GuideCard {
  // 메타 정보
  id: string;                    // 가이드 ID (예: "guide_youtube_start")
  category: string;              // 7개 부업 카테고리
  sub_category: string;          // 서브 카테고리 (예: "유튜브")

  // 카드 표지
  title: string;                 // 제목 (예: "유튜브 부업 시작 전 체크리스트")
  summary: string;               // 1~2문장 요약
  tags: string[];                // 키워드 태그 (검색용)
  thumbnail?: string;            // 썸네일 이미지 URL (선택)

  // 본문 콘텐츠
  pre_start_checklist: string[]; // 시작 전 준비물 / 체크리스트
  failure_factors: Array<{       // 주요 실패 요인 TOP3
    rank: number;
    label: string;
    description: string;
  }>;
  success_lessons: Array<{       // 성공 사례에서 배운 점
    label: string;
    description: string;
  }>;
  recommended_time: string;      // 추천 시간 투입 (예: "주 5~10시간")
  recommended_investment: string; // 추천 초기 투자금 (예: "10만원 이하")
  warnings: string[];            // 주의사항 (사기 / 위험 키워드)

  // 사이드픽 연결
  related_cases_url: string;     // 사이드픽 관련 실패 사례 검색 URL
  related_case_ids?: string[];   // 대표 관련 사례 ID 3개 (선택)

  // 메타데이터
  created_at: string;            // 작성일
  updated_at: string;            // 마지막 업데이트일
  view_count: number;            // 조회수
  helpful_count: number;         // "도움됨" 카운트
  sources: string[];             // 출처 (인용한 사이트 / 책 등)
}
```

## 5. 가이드 카드 예시 (콘텐츠 작성 시 참고)

### 예시 — "유튜브 부업 시작 전 체크리스트"

```yaml
id: guide_youtube_start
category: 콘텐츠·SNS
sub_category: 유튜브

title: 유튜브 부업 시작 전 체크리스트
summary: 유튜브 부업으로 수익을 내려면 평균 6개월~1년의 시간 투자가 필요해요. 시작 전 7가지를 확인해보세요.
tags: [유튜브, 콘텐츠, 광고, 채널, 구독자]

pre_start_checklist:
  - 채널 컨셉을 한 문장으로 설명할 수 있나요?
  - 주 3회 이상 영상 업로드가 가능한가요?
  - 썸네일 / 영상 편집 도구를 사용할 수 있나요?
  - 광고 수익 조건 (구독자 1,000명 + 시청 시간 4,000시간)을 알고 있나요?
  - 1년 이상 지속할 의지가 있나요?
  - 광고 외 수익화 방법 (협찬 / 멤버십 등)을 알고 있나요?
  - 본업·생활에 무리되지 않는 시간 분배가 가능한가요?

failure_factors:
  - rank: 1
    label: 마케팅 부족
    description: 채널 컨셉이 명확하지 않거나 타겟 분석 없이 시작하는 경우
  - rank: 2
    label: 수익 구조 이해 부족
    description: 광고 수익화 조건을 모르고 시작해서 동기 부여 잃는 경우
  - rank: 3
    label: 시간 관리
    description: 본업과 병행이 어려워 업로드 주기가 불규칙해지는 경우

success_lessons:
  - label: 꾸준한 업로드
    description: 성공 채널의 평균 업로드 주기는 주 3회. 1년 이상 지속이 핵심.
  - label: 명확한 컨셉
    description: "○○하는 ○○ 채널"처럼 한 줄로 설명 가능한 채널이 성장 빠름.
  - label: 타겟 분석
    description: 시청자 페르소나를 명확히 설정해서 콘텐츠 방향성 결정.

recommended_time: 주 10~15시간 (영상 1편 = 3~5시간 기준 주 3편)
recommended_investment: 0~30만원 (마이크 / 편집 프로그램)

warnings:
  - "구독자 살게 하는 마케팅 업체" 같은 광고는 사기 가능성 높음
  - 광고 수익 보장 약속은 의심
  - 단기 수익 강조 콘텐츠는 위험

related_cases_url: /experiences?category=콘텐츠·SNS&sub=유튜브&type=failure

sources:
  - 유튜브 공식 크리에이터 가이드
  - 사이드픽 사용자 사례 분석 (콘텐츠·SNS 카테고리 100건)

updated_at: 2026-05-21
```

## 6. 콘텐츠 작성 가이드 (5주차 AI 파트 작업 시 참고)

### 톤 가이드
- **객관적 + 따뜻한** 톤
- "반드시", "절대" 같은 단정적 표현 X
- "~할 가능성이 높아요", "~한 경향이 있어요" 같은 유연한 표현
- 사용자가 부담스럽지 않게 격려하는 문구 포함

### 길이 가이드
- 카드 본문 총 **1000~1500자** (모바일 스크롤 1~2회)
- 체크리스트 / 실패 요인 / 성공 교훈은 **3~7개 항목**
- 각 항목 설명 **30~60자**

### 출처 명시 (법적·신뢰성 측면)
- 외부 자료 인용 시 반드시 출처 표시
- 사이드픽 사용자 사례 분석 인용 시: "사이드픽 사용자 사례 분석 (카테고리명 N건)"
- 통계 수치 인용 시 출처 + 시점 함께 표시

### 작성 우선순위
- 5주차에 **7개 카테고리 × 3~5개 가이드 = 약 21~35개** 작성
- MVP 단계에서는 **핵심 가이드 위주** (각 카테고리 인기 부업 1~2개)
- v2 고도화에서 가이드 확장

## 7. 검색 기능 명세 (BE 5주차 구현)

### 검색 방식
- 키워드 검색 (제목 / 요약 / 태그)
- 카테고리 필터
- 정렬: 인기순 / 최신순 / 도움됨순

### API Endpoint 제안
```
GET /api/guides/search?q={query}&category={category}&sort={sort}
GET /api/guides/{guide_id}
GET /api/guides/categories
```

### 검색 알고리즘
- MVP에서 활용한 FAISS 검색 활용 가능 (가이드 임베딩)
- 또는 단순 키워드 매칭 (학생 프로젝트 규모에선 충분)
