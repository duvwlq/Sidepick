## 1. 페이지 목적 — 왜 부업 가이드 페이지?

### MVP 학습
- **사이드픽은 실패 사례 분석 + AI 가이드 중심**
- 사용자가 "기본적인 정보"는 어디서 얻나? → MVP에서는 부재
- PD 강사님: **"솔루션이 아닌 기본 툴"** 컨셉 제안 — 사용자가 부업 시작 전에 참고할 수 있는 기본 정보 제공

### 고도화 방향
- **부업 시작 전 / 중 / 후에 참고할 수 있는 가이드** 제공
- 검색 가능한 구조 (사용자가 원하는 정보 빠르게 찾기)
- 사이드픽 사례 검색과 연결 (선순환)

### 사용자 시나리오

**시나리오 A — 부업 분야 진입 (택1 분야 탐색)**
```
1. 사용자가 "유튜브 부업 시작해볼까?" 고민
   → 부업 가이드 페이지 검색 "유튜브"
   → 유튜브 부업 가이드 카드 노출 (시작 전 체크리스트 / 주요 실패 요인 등)
   → 사이드픽 사례 검색으로 연결 ("유튜브 실패 사례 보기")
```

**시나리오 B — 횡단 주제 진입 (공통 고민 해결)**
```
1. 스마트스토어 부업 운영 중인 사용자가 "사업자 등록 어떻게 해?" 고민
   → 부업 가이드 페이지에서 "세금·사업자" 카테고리 칩 선택
   → "개인사업자 등록 가이드" 카드 노출 (간이/일반 차이 / 신청 방법 / 4대보험 영향)
   → 카드 하단 "관련 부업 분야: 온라인 판매·이커머스" 링크로 연결
```

**시나리오 C — 에이전트 C에서 가이드로 유도 (챗봇 ↔ 가이드 연동)**
```
1. 사용자가 챗봇에게 "번아웃 와서 부업 그만두고 싶어"라고 질문
   → 챗봇은 횡단 주제(`mental`)라 사례·통계 분석 불가
   → "멘탈관리·번아웃 카테고리 가이드 페이지를 확인해보세요" 응답 [안내: 가이드 페이지 안내]
   → 사용자 가이드 페이지 진입 → 번아웃 회복 가이드 카드 확인
```

## 2. 페이지 구성 — 3개 영역

### 영역 1: 검색창 + 카테고리 칩 (상단)
- 검색창 (placeholder: "어떤 부업 정보를 찾으세요?")
- 16개 카테고리 칩 (필터) — 부업 분야 7개 + 횡단 주제 9개
  - 가로 스크롤 또는 2열 그리드로 노출 (UI 디자인은 PD 판단)
- 인기 검색어 (선택 — 사용자 데이터 누적 후)

### 영역 2: 가이드 카드 리스트 (메인)
- 카드 그리드 (모바일 1열 / 웹 2~3열)
- 가이드 카드 = 1개 가이드라인 단위
- 카드 정렬: 인기순 / 최신순 / 카테고리순

### 영역 3: 사이드픽 사례 연결 (하단)
- "관련 실패 사례 보기" 버튼
- 사이드픽 사례 검색 페이지로 이동

## 3. 16개 카테고리 + 서브 카테고리

카테고리는 **2개 층**으로 구성됩니다.

| 층 | 카테고리 # | 정의 | 에이전트 C 통계 분석 |
|---|---|---|---|
| **부업 분야** | 1~7번 | "무슨 부업을 하느냐" — 택1 분야 | ✅ **분석 대상** (`ALLOWED_CATEGORIES` enum) |
| **횡단 주제** | 8~16번 | "부업하면서 공통으로 마주치는 일" | ❌ 가이드 콘텐츠 전용 |

> 📌 자세한 정의는 `docs/사이드픽-서비스-정책.md v1.1` 참조

### A. 부업 분야 (1~7번) — 분석 대상 7개

#### 1) 온라인 판매·이커머스 (slug: `commerce`)
- 스마트스토어
- 쿠팡 위탁판매
- 11번가·G마켓
- 자사몰 (Cafe24, 아임웹 등)
- 해외 직구·구매대행

#### 2) 콘텐츠·SNS (slug: `content-sns`)
- 유튜브
- 인스타그램
- 블로그 (네이버 / 티스토리)
- 틱톡·릴스
- 트위치·아프리카TV

#### 3) 디지털·지식판매 (slug: `digital-product`)
- 전자책 (PDF / Kindle)
- 온라인 강의 (인프런 / 클래스101 / 패스트캠퍼스)
- 템플릿·디자인 자산 판매
- 음원·이미지 라이선스 판매

#### 4) 플랫폼 노동 (slug: `platform-labor`)
- 배달 알바 (배민 커넥트 / 쿠팡이츠)
- 대리운전
- 쿠팡 플렉스
- 가사 도우미 (미소 / 시터 등)

#### 5) 재능·프리랜서 (slug: `talent`)
- 크몽 / 숨고 / 탈잉
- 외주 디자인·개발
- 과외·튜터링
- 번역·통역

#### 6) 투자·재테크 (slug: `investment`)
- 주식 (장기 투자 위주 — 단타는 안전 정책에서 차단)
- 코인 (장기 보유 위주 — 단타는 안전 정책에서 차단)
- 부동산 (소액 투자)
- P2P 투자
- 채권·ETF

#### 7) 오프라인 부업 (slug: `offline`)
- 공유 오피스 운영
- 플리마켓·핸드메이드
- 카페·소품샵 운영
- 강의 (오프라인 클래스)

### B. 횡단 주제 (8~16번) — 가이드 콘텐츠 전용 9개

부업 분야와 무관하게 모든 부업자가 공통으로 마주치는 주제. **통계 분석 대상이 아니며**, 가이드 카드 형태로만 노출됩니다.

#### 8) 부업 시작전 공통 (slug: `pre-start`)
- 부업 마인드셋 (현실적 기대치 설정)
- 부업 종류 선택법 (적성·시간·자본 매칭)
- 시간 관리 기초 (본업과 병행)
- 본업과의 관계 정리 (가족·회사 동의)

#### 9) 세금·사업자 (slug: `tax`)
- 사업자 등록 (개인사업자 / 간이과세자 / 일반과세자)
- 종합소득세 신고
- 부가가치세
- 원천세
- 4대 보험 (직장가입자 vs 지역가입자)

#### 10) 본업+부업 (slug: `work-balance`)
- 시간 분배 전략
- 본업 회사 정책 확인 (취업규칙·근로계약서)
- 부업 금지 회사 대응
- 워라밸 유지
- 가족 동의 받기

#### 11) 마케팅·광고 운영 (slug: `marketing`)
- SNS 마케팅 기초
- 광고 채널 선택 (네이버·메타·구글 광고)
- 콘텐츠 마케팅 전략
- 인플루언서 협업
- 광고비 효율 측정

#### 12) 도구·툴 추천 (slug: `tools`)
- 부업 관리 앱 (할 일·일정 관리)
- 회계 도구 (엑셀·통장관리·세무 SaaS)
- 디자인 도구 (Canva·Figma·Photoshop)
- AI 도구 활용 (ChatGPT·Claude·이미지 생성)
- 협업 도구 (Notion·Slack·Discord)

#### 13) 멘탈관리·번아웃 (slug: `mental`)
- 번아웃 사인 (조기 인지)
- 회복 방법
- 동기 부여 유지
- 스트레스 관리
- 휴식 전략 (워크 사이클)

#### 14) 법률·계약 (slug: `legal`)
- 표준 계약서 작성 (외주·프리랜서)
- 저작권·상표권 기초
- 개인정보보호 (사업자 의무)
- 분쟁 해결 (소액 분쟁·조정)
- 부업 관련 법규 (전자상거래법·통신판매업 신고 등)

#### 15) 회계·장부 (slug: `accounting`)
- 수입·지출 관리 기초
- 소득 신고 (종합소득세·근로소득과 합산)
- 영수증·증빙 관리
- 세금계산서 발행·수취
- 부업용 통장 분리

#### 16) 부업 인사이트 (slug: `insight`)
- 트렌드 분석 (요즘 뜨는 부업)
- 성공 사례 분석 (공통 패턴)
- 실패 패턴 (사이드픽 데이터 기반)
- 시장 변화 (플랫폼 정책·규제)
- 신규 부업 소개 (실험적 분야)

## 4. 가이드라인 포맷 — 필드 구조

### 가이드 카드 필드 정의

```typescript
interface GuideCard {
  // 메타 정보 (전 카테고리 공통 — 필수)
  id: string;                    // 가이드 ID (예: "guide_youtube_start")
  category: string;              // 16개 카테고리 한글명 (예: "콘텐츠·SNS")
  category_slug: string;         // 16개 카테고리 slug (예: "content-sns")
  category_type: 'business_field' | 'cross_topic';  // 부업 분야 vs 횡단 주제
  sub_category: string;          // 서브 카테고리 (예: "유튜브" / "사업자 등록")

  // 카드 표지 (전 카테고리 공통 — 필수)
  title: string;                 // 제목
  summary: string;               // 1~2문장 요약
  tags: string[];                // 키워드 태그 (검색용)
  thumbnail?: string;            // 썸네일 이미지 URL (선택)

  // 본문 콘텐츠 — 카테고리 type별로 필수/선택 다름
  // ✅ 부업 분야(business_field): pre_start_checklist / failure_factors / success_lessons / recommended_time / recommended_investment 필수
  // ✅ 횡단 주제(cross_topic): pre_start_checklist / warnings 위주, recommended_* 는 N/A
  pre_start_checklist?: string[]; // 시작 전 준비물 / 체크리스트 (부업 분야 필수 / 횡단 주제 선택)
  failure_factors?: Array<{       // 주요 실패 요인 TOP3 (부업 분야 전용)
    rank: number;
    label: string;
    description: string;
  }>;
  success_lessons?: Array<{       // 성공 사례에서 배운 점 (부업 분야 전용)
    label: string;
    description: string;
  }>;
  recommended_time?: string;      // 추천 시간 투입 (부업 분야 전용)
  recommended_investment?: string; // 추천 초기 투자금 (부업 분야 전용)
  warnings?: string[];            // 주의사항 (사기 / 위험 키워드) — 전 카테고리 선택

  // 횡단 주제 전용 필드 (cross_topic 카드만)
  procedure_steps?: Array<{       // 절차 단계 (예: 사업자 등록 → 6단계)
    step: number;
    title: string;
    description: string;
  }>;
  faq?: Array<{                   // 자주 묻는 질문 + 답
    question: string;
    answer: string;
  }>;
  legal_disclaimer?: string;      // 법률·세금·계약 카테고리: "전문가 상담 권장" 안내

  // 사이드픽 연결 (부업 분야 필수 / 횡단 주제 선택)
  related_cases_url?: string;     // 사이드픽 관련 실패 사례 검색 URL
  related_case_ids?: string[];    // 대표 관련 사례 ID 3개 (선택)
  related_guide_ids?: string[];   // 관련 가이드 카드 ID (예: 사업자 등록 → 종합소득세)

  // 메타데이터 (전 공통 — 필수)
  created_at: string;
  updated_at: string;
  view_count: number;
  helpful_count: number;
  sources: string[];              // 출처 (인용한 사이트 / 책 / 법령 등)
}
```

### 카테고리 type별 필수 필드 정리

| 필드 | `business_field` (부업 분야) | `cross_topic` (횡단 주제) |
|---|---|---|
| `pre_start_checklist` | ✅ 필수 | 🟡 선택 |
| `failure_factors` | ✅ 필수 (TOP3) | ❌ N/A |
| `success_lessons` | ✅ 필수 | ❌ N/A |
| `recommended_time` | ✅ 필수 | ❌ N/A |
| `recommended_investment` | ✅ 필수 | ❌ N/A |
| `warnings` | 🟡 선택 | 🟡 선택 |
| `procedure_steps` | ❌ N/A | ✅ 권장 (절차 있는 주제) |
| `faq` | 🟡 선택 | ✅ 권장 |
| `legal_disclaimer` | ❌ N/A | ✅ 필수 (법률·세금·회계만) |
| `related_cases_url` | ✅ 필수 | 🟡 선택 |

## 5. 가이드 카드 예시 (콘텐츠 작성 시 참고)

### 예시 A — 부업 분야 카드 (business_field)

```yaml
id: guide_youtube_start
category: 콘텐츠·SNS
category_slug: content-sns
category_type: business_field
sub_category: 유튜브

title: 유튜브 부업 시작 전 체크리스트
summary: 유튜브 부업으로 수익을 내려면 평균 6개월~1년의 시간 투자가 필요해요. 시작 전 7가지를 확인해보세요.
tags: [유튜브, 콘텐츠, 광고, 채널, 구독자]

pre_start_checklist:
  - 채널 컨셉을 한 문장으로 설명할 수 있나요?
  - 주 3회 이상 영상 업로드가 가능한가요?
  - 썸네일 / 영상 편집 도구를 사용할 수 있나요?
  - 광고 수익 조건 (구독자 1,000명 + 시청 시간 4,000시간)을 알고 있나요?
  - 1년 이상 지속할 의지가 있나요?
  - 광고 외 수익화 방법 (협찬 / 멤버십 등)을 알고 있나요?
  - 본업·생활에 무리되지 않는 시간 분배가 가능한가요?

failure_factors:
  - rank: 1
    label: 마케팅 부족
    description: 채널 컨셉이 명확하지 않거나 타겟 분석 없이 시작하는 경우
  - rank: 2
    label: 수익 구조 이해 부족
    description: 광고 수익화 조건을 모르고 시작해서 동기 부여 잃는 경우
  - rank: 3
    label: 시간 관리
    description: 본업과 병행이 어려워 업로드 주기가 불규칙해지는 경우

success_lessons:
  - label: 꾸준한 업로드
    description: 성공 채널의 평균 업로드 주기는 주 3회. 1년 이상 지속이 핵심.
  - label: 명확한 컨셉
    description: "○○하는 ○○ 채널"처럼 한 줄로 설명 가능한 채널이 성장 빠름.
  - label: 타겟 분석
```

## 6. 콘텐츠 작성 가이드 (5주차 AI 파트 작업 시 참고)

### 톤 가이드
- **객관적 + 따뜻한** 톤
- "반드시", "절대" 같은 단정적 표현 X
- "~할 가능성이 높아요", "~한 경향이 있어요" 같은 유연한 표현
- 사용자가 부담스럽지 않게 격려하는 문구 포함

### 길이 가이드
- 카드 본문 총 **1000~1500자** (모바일 스크롤 1~2회)
- 체크리스트 / 실패 요인 / 성공 교훈은 **3~7개 항목**
- 각 항목 설명 **30~60자**

### 출처 명시 (법적·신뢰성 측면)
- 외부 자료 인용 시 반드시 출처 표시
- 사이드픽 사용자 사례 분석 인용 시: "사이드픽 사용자 사례 분석 (카테고리명 N건)"
- 통계 수치 인용 시 출처 + 시점 함께 표시

### 작성 우선순위
- 5주차에 **16개 카테고리 × 2~3개 가이드 = 약 32~48개** 작성
  - 부업 분야 7개 × 평균 3개 = 21개
  - 횡단 주제 9개 × 평균 2개 = 18개
- **핵심 가이드 위주** (각 카테고리 인기 주제 1~2개부터 시작)
- 작성 우선순위:
  1. **1순위** — 부업 분야 7개 카테고리 핵심 가이드 (각 1개씩 = 7개)
  2. **2순위** — 횡단 주제 9개 카테고리 핵심 가이드 (각 1개씩 = 9개)
  3. **3순위** — 각 카테고리 보강 가이드 (시간 여유 따라)
- 이후 사용자 검색 데이터 누적 → 인기 검색어 기반 가이드 추가 작성

## 9. PD 디자인 기준 (전달용)

### 디자인 요소
- **카드 디자인**: 깔끔한 미니멀 카드 / 카테고리 type별 컬러 차별화 (부업 분야 = 메인 컬러 / 횡단 주제 = 서브 컬러)

- **카드 형식 차별화**: 부업 분야는 체크리스트·실패요인 위주, 횡단 주제는 절차 단계·FAQ 위주 — 카드 UI 컴포넌트 2종으로 구분
