# 백엔드 운영 안정화 체크리스트

## 인증 제공자 설정
- `APP_AUTH_LOCAL_ENABLED`
- `APP_AUTH_KAKAO_ENABLED`
- `APP_AUTH_GOOGLE_ENABLED`

운영 기본값:
- `APP_AUTH_LOCAL_ENABLED=false`
- `APP_AUTH_KAKAO_ENABLED=true`
- `APP_AUTH_GOOGLE_ENABLED=false`

## 기본 점검 항목
- `GET /api/health`
- `GET /api/users/me`
- 카카오 로그인 성공/실패 로그
- 경험 목록 조회 응답 시간
- 경험 상세 조회 시 `viewCount` 증가 여부

## 로그인 실패 원인
### 이메일 로그인
- `Email login is not available right now.`
  - 운영에서 로컬 인증 비활성 상태
- `Email or password is invalid.`
  - 계정 없음 또는 비밀번호 오류
- `This account must sign in with a social login provider.`
  - 소셜 계정에 이메일 로그인 시도

### 카카오 로그인
- `KAKAO OAuth is not configured on the server.`
  - 카카오 키 미설정
- `OAuth token exchange failed.`
  - 인가 코드 만료, Redirect URI 불일치, 카카오 측 오류
- `Failed to fetch Kakao user info.`
  - 카카오 사용자 정보 조회 실패

## 경험 등록/조회 점검
- 카테고리 ID 유효성
- 실패 원인 최소 1개 입력
- 음수 기간/투자금/월수익 차단
- 목록 필터 확인
  - `q`
  - `sort`
  - `categoryId`
  - `failureReason`
  - `durationMonthsMin`, `durationMonthsMax`
  - `investmentAmountMin`, `investmentAmountMax`

## 로그 확인 포인트
- 인증 실패 로그
- OAuth 토큰 교환 실패 로그
- 경험 등록 검증 실패 로그
- AI 분석 실패 로그

## 운영 이슈 대응 순서
1. 인증 불가 여부 확인
2. `/api/health` 확인
3. 환경변수 누락 확인
4. DB 연결 상태 확인
5. Nginx 및 도메인 연결 확인
