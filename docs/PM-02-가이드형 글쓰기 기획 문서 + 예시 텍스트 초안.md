# 가이드형 글쓰기 기획서

**대상**: PD (이은성) — UI 디자인 기준 / AI (오혜림) — 예시 텍스트 작성 인계
**티켓**: PM-02
**연관**: W2-AI (가이드형 글쓰기 예시 텍스트 완성)

> 📌 본 문서는 MVP에서 도출된 글쓰기 허들 줄이기 피드백을 고도화에서 발전시킨 기획입니다.
> 자율서술 → 구조화 입력 방식으로 전환하며, 사용자가 빈 화면 대신 가이드를 받으며 작성할 수 있도록 합니다.

---

## 1. 배경 — 왜 가이드형 글쓰기로?

### MVP 단계 학습
- **글쓰기 4→3단계 단계 내용 변경**
- **자유서술 50자 → 10자** 완화
- **실패 원인 단계 제거**
- **베타테스트 13명 설문 결과**: "글쓰기가 너무 어렵다 / 뭘 써야 할지 모르겠다" 응답 다수

### 남은 문제
- 사용자가 10자 자유 서술하라고 해도 **빈 화면에서 막막함**
- 작성된 글의 **데이터 품질 편차 큼** (구조화된 입력이 부족하면 AI 분석 어려움)
- **AI 분석 품질**이 사용자 입력 품질에 좌우됨

### 고도화 방향
1. **가이드 제공**: 예시 텍스트로 사용자가 어떻게 써야 할지 안내
2. **데이터 품질 향상**: 구조화된 정보가 자연스럽게 들어가게 유도
3. **부담 최소화**: 가이드는 선택사항 (강요하지 않음)

## 2. 글쓰기 흐름 — 3단계 유지 (MVP 기반)

```
1단계: 카테고리 선택 (7개 부업 카테고리 + 서브 카테고리)
   ↓
2단계: 다이얼식 입력 (기간 / 투자금 / 하루 할애 시간 / 본업 병행 여부)
   ↓
3단계: 자율 서술 (가이드형 — 핵심 고도화 포인트)
```

→ 1·2단계는 MVP와 동일, **3단계에 가이드형 UI 추가**

## 3. 가이드 방식 — 옵션 비교 + 추천

### 옵션 A: Placeholder 텍스트
- 입력창에 회색 예시 텍스트 표시
- 사용자가 입력 시작하면 사라짐
- **장점**: 가장 가벼움 / 구현 쉬움
- **단점**: 예시가 1개로 제한적

### 옵션 B: 예시 텍스트 카드 (별도 영역 노출)
- 입력창 위 또는 옆에 "예시 보기" 카드 노출
- 사용자가 카드를 보고 참고하면서 작성
- 카드는 토글 가능 (사용자가 숨길 수 있음)
- **장점**: 다양한 예시 노출 가능 / 부담 ↓ / 데이터 품질 ↑
- **단점**: UI 공간 필요

### 옵션 C: 실시간 AI 어시스트
- 사용자가 입력 중 AI가 질문 카드 제시 (에이전트 A 기능)
- **장점**: 가장 동적 / 데이터 품질 가장 ↑
- **단점**: 구현 복잡 / 토큰 비용 (이건 에이전트 A 영역으로 별도)

### 제안: **옵션 B**
- MVP 학습 (글쓰기 부담 ↓) 유지
- 사용자가 부담 없이 참고 가능
- AI 분석 품질 향상 효과 큼

## 4. UI 디자인 기준 (PD 전달용)

### 화면 레이아웃 (3단계 자유 서술 화면)

```
┌──────────────────────────────────────────────┐
│  [1단계 카테고리] [2단계 다이얼] [3단계 자유서술]     │
│                                              │
│  ⏎ 어떤 부업이었는지 자유롭게 적어주세요 (최소 10자)    │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ ✏️ 글쓰기 입력창                          │  │
│  │ (사용자 입력 영역)                        │   │
│  │                                        │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ 💡 예시 보기 (참고만 — 닫기)                │  │
│  │ ─────────────────────────────────      │  │
│  │ "유튜브 채널을 만들었는데 3개월 동안 영상 5개    │  │
│  │  올리고 컨셉도 자주 바뀌어서 결국 그만뒀어요."    │  │
│  │                                        │  │
│  │ 다른 예시 보기 →                          │  │
│  └────────────────────────────────────────┘  │
│                                              │
│              [이전]    [작성 완료]              │
└──────────────────────────────────────────────┘
```

### UI 컴포넌트 명세

#### 1) 예시 카드 (`ExampleCard`)
- **위치**: 입력창 아래 (모바일) / 옆 (태블릿·웹)
- **배경**: 옅은 회색 (`#F9F9F9`) — 입력창과 시각적 구분
- **테두리**: 점선 (옵션) — "참고 자료" 느낌
- **헤더**: "💡 예시 보기" + 닫기 버튼 (X)
- **본문**: 예시 텍스트 (1개씩 표시)
- **푸터**: "다른 예시 보기 →" 버튼 (다음 예시 슬라이드)

#### 2) 닫기 토글
- 사용자가 X 버튼 클릭 시 카드 숨김
- 숨김 상태는 세션 동안 유지 (다음 글쓰기 시에는 다시 노출)
- **이유**: 한 번 본 사용자가 매번 보지 않아도 됨

#### 3) 다른 예시 보기
- 같은 카테고리에서 다양한 실패 패턴별 예시 노출
- 슬라이드 형식 (좌우 화살표)

### 톤·문구 가이드
- 예시 텍스트는 **부담스럽지 않은 길이** (30~60자)
- 헤더 문구: "참고만 — 그대로 따라하지 않아도 됩니다" (부담 ↓)
- 닫기 버튼은 명확하게 (X)

## 5. 예시 텍스트 초안 (7개 부업 카테고리)

> 본 예시는 **초안**입니다. 2주차에 AI 파트에서 업종별로 더 다양한 예시 텍스트 작성 예정.

### 1) 온라인 판매·이커머스
```
"스마트스토어를 시작했는데 마케팅 비용 대비 매출이 안 나와서 6개월 만에 중단했어요."

"쿠팡 위탁판매 시작했는데 경쟁이 심해서 가격을 계속 내리다 손해 보고 그만뒀어요."
```

### 2) 콘텐츠·SNS
```
"유튜브 채널을 만들었는데 3개월 동안 영상 5개 올리고 컨셉도 자주 바뀌어서 결국 그만뒀어요."

"인스타그램으로 부수입 노렸는데 팔로워가 안 늘어서 1년 만에 포기했어요."
```

### 3) 디지털 상품·지식
```
"전자책 만들어서 팔려고 했는데 어떻게 홍보할지 몰라서 안 팔리고 끝났어요."

"온라인 강의 만들었는데 플랫폼 수수료가 너무 커서 손익분기점 못 넘었어요."
```

### 4) 플랫폼 노동
```
"배달 알바 시작했는데 보험·기름값 빼니 시급이 너무 낮아서 한 달 만에 그만뒀어요."

"쿠팡 플렉스 했는데 시간 대비 수익이 안 맞아서 중단했어요."
```

### 5) 재능·프리랜서
```
"크몽에서 디자인 외주 받으려 했는데 단가가 낮아서 시간 대비 수익이 안 나왔어요."

"숨고에서 과외 매칭 받으려 했는데 경쟁이 심해서 학생을 못 구했어요."
```

### 6) 투자·재테크
```
"주식 시작했는데 단타 위주로 하다가 1년 만에 원금 절반 손해 보고 그만뒀어요."

"코인 투자 시작했는데 변동성이 너무 커서 멘탈이 못 버텨서 중단했어요."
```

### 7) 오프라인 부업
```
"공유 오피스 운영하려고 했는데 초기 투자금이 너무 커서 시작도 못 했어요."

"플리마켓 시작했는데 자리세 + 재료비 대비 매출이 안 나와서 그만뒀어요."
```

## 6. 작업 인계 — AI 파트 (2주차)

### 2주차 작업 (W2-AI)
- **티켓**: [가이드형 글쓰기 예시 텍스트 완성]
- **마감**: 5/29(목) 밤까지
- **목표**: 위 초안 기반으로 업종별 다양한 예시 텍스트 완성

### 작성 가이드
1. 각 카테고리별 **5~8개 예시** 작성 (실패 패턴별로 다양화)
2. 길이: **30~60자** (부담 없는 분량)
3. 톤: **자연스러운 1인칭** (사용자가 직접 쓰는 느낌)
4. 다양한 실패 패턴 커버:
   - 마케팅 부족 / 수익 구조 이해 부족 / 시간 관리 / 정보 부족 / 경쟁 심화 / 운영 지속성 / 수익화 연결
5. 카테고리당 약 7개 패턴별 1개씩 작성하면 7×7 = 49개

### BE 전달 형식
```json
{
  "category": "콘텐츠·SNS",
  "examples": [
    {
      "pattern": "마케팅 부족",
      "text": "..."
    },
    {
      "pattern": "수익 구조 이해 부족",
      "text": "..."
    },
    ...
  ]
}
```

→ BE는 이 데이터를 받아 글쓰기 화면에서 카테고리에 맞는 예시를 렌더링

## 8. 효과 측정 (베타테스트 1회에서 확인)

### 베타테스트 1회 설문 (Q4·Q5 — 가이드형 글쓰기 효과)
- Q4. 예시 텍스트가 글 작성에 도움이 되었나요? (1~5점)
- Q5. 기존 자율서술 방식과 비교해 이번 방식이 더 편하게 느껴지나요? (1~5점)
- Q6. 글을 쓸 때 아직 어렵거나 빠진 안내가 있다면 적어주세요. (주관식)

### 성공 기준
- Q4, Q5 평균 점수 **4.0/5.0 이상**
- 자유 서술 길이 평균 **20자 이상** (MVP에선 평균 12자 추정)
- AI 분석 신뢰도 평균 **0.7 이상** (에이전트 B 자기검증 기준)
