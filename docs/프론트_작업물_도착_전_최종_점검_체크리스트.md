# 프론트 작업물 도착 전 최종 점검 체크리스트

이 문서는 프론트 작업물이 들어오기 전에 백엔드, 문서, 통합 브랜치 기준으로 미리 정리해야 할 항목을 정리한 체크리스트입니다.

## 1. 브랜치 기준 정리

- `main`: 기준 브랜치
- `main-backup-20260423`: 백업 브랜치
- `Sidepick-merge-branch`: 통합 및 배포 준비 브랜치
- `feature/backend`: 백엔드 기능 작업 브랜치
- `feature/ai`: AI 작업 브랜치
- `feature/fe-setup`: 프론트 작업 브랜치

확인 사항:

- `main`에는 직접 작업하거나 직접 push하지 않는다.
- 실제 통합은 `Sidepick-merge-branch`에서 진행한다.
- 프론트, 백엔드, AI 작업은 각자 기능 브랜치에서 유지한다.

## 2. 백엔드 구현 상태 점검

현재 우선 확인할 기능:

- 이메일 회원가입 및 로그인
- 이메일 인증 요청 및 인증 확인
- 카카오 OAuth 로그인
- 구글 OAuth 로그인
- 사용자 프로필 조회
- 경험 등록/수정/삭제
- 경험 상세 조회
- AI 분석 조회/생성
- 카테고리 조회
- 헬스체크

확인 포인트:

- 와이어프레임 기준으로 필요한 필드가 DTO와 엔티티에 반영되어 있는지 확인
- 이메일 미인증 계정의 쓰기 제한 정책이 유지되는지 확인
- 소셜 로그인 사용자의 계정 생성 및 연결 흐름이 정상인지 확인

## 3. 프론트 연동 준비 점검

프론트 작업물이 들어오면 바로 확인해야 할 값:

- 카카오 콜백 경로
- 구글 콜백 경로
- 프론트 토큰 저장 방식
- 로그인 성공 후 이동 경로
- 경험 등록 요청 바디 필드 구성

프론트 전달 문서:

- `docs/frontend-auth-handoff.md`
- `server/AUTH_FLOW_MVP.md`

## 4. 배포 환경 점검

필수 환경 변수:

- `APP_OAUTH_KAKAO_CLIENT_ID`
- `APP_OAUTH_KAKAO_CLIENT_SECRET`
- `APP_OAUTH_GOOGLE_CLIENT_ID`
- `APP_OAUTH_GOOGLE_CLIENT_SECRET`
- 메일 인증 관련 환경 변수

확인 사항:

- 운영 서버에 OAuth 환경 변수가 들어가 있는지 확인
- 로컬 `.env`와 운영 `backend.env`가 서로 다른 값을 올바르게 갖고 있는지 확인
- 민감 정보가 Git에 들어가지 않았는지 점검

## 5. 문서 정리 점검

우선 유지할 문서:

- README
- `server/README.md`
- `server/AUTH_FLOW_MVP.md`
- `docs/frontend-auth-handoff.md`

추가 정리 대상:

- 느슨하게 남아 있는 메모성 문서
- 포스트맨 예시 중 중복 파일
- 화면 캡처 자료

원칙:

- 지금은 삭제보다 분류가 우선
- 사용자 작업물일 가능성이 있는 문서는 바로 삭제하지 않는다

## 6. 프론트 작업물 도착 직후 확인 순서

1. 브랜치 확인
2. 프론트 콜백 URI 확인
3. 로그인 버튼 연결
4. 카카오/구글 로그인 테스트
5. 이메일 인증 UI 연결
6. 경험 등록 API 연결
7. AI 분석 결과 화면 연결
8. 통합 브랜치에서 빌드/테스트
9. 배포 전 최종 점검

## 7. 현재 기준 남은 백엔드 후속 작업

프론트 없이도 미리 생각해 둘 항목:

- 경험 목록 검색/정렬 API 확장
- 좋아요/북마크 구조 추가 여부
- 유사 사례 공개 조회 방식 정리
- 분석 결과 화면 전용 응답 구조 필요성 검토

이 항목들은 프론트 화면 구조가 들어온 뒤 우선순위를 다시 조정하는 것이 안전합니다.
