# BE-04 환경 변수 명세

## 전달 산출물

- 환경 변수 명세 문서
- `.env.example`: [../.env.example](../.env.example)

## 최종 결정 요약

1. 모델, 프롬프트, Mock, 토큰/비용, 큐잉, LangSmith 설정은 전부 환경 변수로 분리한다.
2. `CLAUDE_MODEL`, `PROMPT_VERSION`, `USE_MOCK_LLM`은 필수 키로 둔다.
3. LangSmith는 `LANGSMITH_*` prefix와 APAC endpoint를 사용한다.
4. 운영 비밀값은 `.env.example`에 넣지 않고 `.env.dev`, `.env.prod` 또는 배포 환경 변수로만 관리한다.

## 팀장 확인 필요 항목

1. `CLAUDE_MODEL=claude-sonnet-4-6` 기본값이 맞는지
2. `PROMPT_VERSION=agent_c_v1` 네이밍을 이대로 갈지
3. 사용자/서비스 비용 cap 키를 `.env.example`에 노출하는 방향이 맞는지
4. LangSmith endpoint를 APAC 기준으로 고정하는지

## 목적

AI 에이전트 운영, 소셜 로그인, 비용 통제, 프롬프트 버전 관리를 코드 하드코딩 없이 환경 변수로 분리한다.

## 파일 전략

커밋 대상:

- `.env.example`

로컬/운영 실제 사용:

- `.env.dev`
- `.env.prod`

운영 원칙:

1. 저장소에는 실제 비밀값을 커밋하지 않는다.
2. `.env.example`는 키 목록과 예시값만 유지한다.
3. 로컬은 `.env.dev`, 운영은 `.env.prod` 또는 배포 환경 변수로 override 한다.

## 환경별 예시

### `.env.dev`

```env
SPRING_PROFILES_ACTIVE=local
USE_MOCK_LLM=true
CLAUDE_MODEL=claude-haiku-4-5
CLAUDE_MODEL_DEV=claude-haiku-4-5
PROMPT_VERSION=agent_c_v1
DAILY_TOKEN_LIMIT_USER=10000
DAILY_COST_CAP_USER=0.50
DAILY_COST_CAP_SERVICE=5.00
MAX_ITERATIONS=7
RESPONSE_TIMEOUT_SEC=30
AI_STREAM_ENABLED=true

```

## 주의사항

1. `CLAUDE_MODEL`은 코드에 하드코딩하지 않는다.
2. 발표 직전 모델 deprecated 대응은 `.env.prod` 한 줄 변경으로 끝나야 한다.
3. Prompt 버전은 `PROMPT_VERSION`으로 선택하고 파일명과 일치시킨다.
4. 토큰/비용 정책은 FE 문구와 BE 차단 로직이 같은 값을 써야 한다.
5. LangSmith는 `LANGSMITH_*` prefix를 사용하고, endpoint는 APAC region이면 `https://apac.api.smith.langchain.com`으로 맞춘다.
6. LangSmith API 키는 `.env`에만 두고 저장소 문서에는 실제 값을 남기지 않는다.
