# 00. Project Overview

## Purpose

SidePick은 부업 실패 경험을 기록하고, 유사 사례를 탐색하고, 분석 리포트를 통해 다음 선택에 도움이 되는 정보를 제공하는 MVP 서비스입니다.

## MVP Scope

현재 MVP 기준 핵심 범위는 아래입니다.

- 실패 경험 작성
- 사례 목록 탐색
- 사례 상세 조회
- 분석 리포트 조회
- 유사 사례 확인
- 인증 및 사용자 기본 흐름

## Core User Flow

1. 사용자가 실패 경험을 작성한다.
2. 저장된 경험을 상세 페이지에서 다시 확인한다.
3. 경험에 대한 분석 리포트를 조회한다.
4. 유사 사례와 가이드를 참고한다.

## Included

- FE: 사례 작성, 탐색, 상세, 인증 UI
- BE: 경험/분석/인증 API
- AI 연동: 분석 요청 및 결과 저장/조회

## Excluded

- 대규모 운영 관리자 기능
- 완전한 데이터 파이프라인 운영 문서
- 실험성 AI 자산 설명을 현재 기준 문서에 직접 포함하는 것
