# 00. Project Overview

## Summary

Sidepick은 **부업 실패 경험을 기록하고, AI가 유사 사례와 다음 액션을 분석해주는 MVP 서비스**입니다.

이 프로젝트는 성공 사례보다 덜 정리되어 있는 실패 경험을 제품 데이터로 바꾸는 데 초점을 맞춥니다.

---

## Problem

부업 관련 정보는 대부분 아래 두 가지로 갈립니다.

- 성공 후기 중심의 콘텐츠
- 맥락 없이 흩어진 실패담

이 구조에서는 사용자가 실제로 막히는 지점을 학습하기 어렵습니다.
Sidepick은 실패 경험을 구조화하고, 다시 탐색 가능한 정보로 재구성합니다.

---

## MVP Goal

MVP의 목표는 다음 3가지를 검증하는 것입니다.

1. 사용자가 실패 경험을 기록할 의사가 있는가
2. 기록된 실패 경험이 탐색 가능한 데이터로 기능하는가
3. AI 분석이 사용자의 다음 판단에 실제 도움을 주는가

---

## Scope

### Included

- 실패 경험 작성
- 경험 목록 탐색
- 경험 상세 조회
- AI 분석 리포트 조회
- 유사 사례 확인
- 기본 인증 / 사용자 흐름
- FAQ / 카테고리형 가이드

### Excluded

- 관리자 콘솔
- 대규모 운영 툴링
- 실시간 큐 기반 분석 파이프라인
- 정교한 추천 모델 운영 자동화

---

## Core User Flow

1. 사용자가 실패 경험을 작성합니다.
2. 백엔드가 경험 데이터를 저장합니다.
3. 분석 요청이 AI 서버로 전달됩니다.
4. 사용자는 사례 상세 화면에서 분석 리포트를 확인합니다.
5. 유사 사례와 FAQ를 보며 다음 선택의 기준을 얻습니다.

---

## Product Value

- 실패를 기록 가능한 데이터로 바꿉니다.
- 개인 경험을 집단 학습 자산으로 확장합니다.
- 감정적인 후기보다 실행 가능한 가이드를 제공합니다.
- 단순 커뮤니티가 아니라 제품형 탐색 경험을 만듭니다.
